Array.prototype.map()
Array Non-Mutating

Purpose: Creates a brand new array populated with the results of calling a provided callback function on every single element in the calling array. Does not mutate the original array.

Returns: A new Array Related Lesson: 08. Arrays & Methods
JavaScript
const prices = [100, 250, 400];
const pricesWithGST = prices.map(price => price * 1.18);
console.log(pricesWithGST); // [118, 295, 472]
Array.prototype.filter()
Array Non-Mutating

Purpose: Creates a shallow copy of a portion of a given array, filtered down to just the elements that pass the test implemented by the provided callback function.

JavaScript
const scores = [45, 88, 92, 35, 78];
const passing = scores.filter(score => score >= 60);
console.log(passing); // [88, 92, 78]
Array.prototype.reduce()
Array Aggregation

Purpose: Executes a user-supplied "reducer" callback on each element of the array, passing in the return value from the calculation on the preceding element. Returns a single accumulated value.

JavaScript
const cart = [{ price: 20 }, { price: 40 }, { price: 15 }];
const total = cart.reduce((acc, item) => acc + item.price, 0);
console.log("Total Bill:", total); // 75
String.prototype.includes()
String Case-Sensitive

Purpose: Performs a case-sensitive search to determine whether one string may be found within another string, returning true or false.

JavaScript
const sentence = "Learning modern vanilla JavaScript!";
console.log(sentence.includes("JavaScript")); // true
console.log(sentence.includes("python"));     // false
String.prototype.split()
String Returns Array

Purpose: Divides a String into an ordered list of substrings by searching for a separator pattern, putting these substrings into an array, and returning the array.

JavaScript
const csv = "red,green,blue,yellow";
const colors = csv.split(",");
console.log(colors); // ['red', 'green', 'blue', 'yellow']
Object.entries() / Object.keys()
Object Inspection

Purpose: Object.keys() returns an array of a given object's own enumerable property names. Object.entries() returns an array of a given object's own string-keyed key-value pairs as [key, value] tuples.

JavaScript
const user = { name: "Ananya", role: "Dev", score: 98 };

for (const [key, val] of Object.entries(user)) {
  console.log(`${key} -> ${val}`);
}
Math.floor() & Math.random()
Math Numbers

Purpose: Math.random() returns a pseudo-random floating-point number between 0 (inclusive) and 1 (exclusive). Math.floor() rounds down to the nearest integer.

JavaScript
// Generate a random integer between min and max (inclusive)
function getRandomInt(min, max) {
  return Math.floor(Math.random() * (max - min + 1)) + min;
}
console.log("Random dice roll:", getRandomInt(1, 6));
document.querySelector() & querySelectorAll()
DOM Selecting

Purpose: querySelector returns the first Element within the document that matches the specified CSS selector. querySelectorAll returns a static NodeList of all matching elements.

JavaScript
const activeCard = document.querySelector(".card.active");
const allButtons = document.querySelectorAll("button.btn-primary");
allButtons.forEach(btn => btn.addEventListener("click", () => console.log("Clicked!")));
Promise.all() & async / await
Asynchronous Concurrency

Purpose: Takes an iterable of promises and returns a single Promise that fulfills when all of the input promises have fulfilled, executing jobs concurrently in parallel.

JavaScript
async function loadDashboard() {
  const [profile, stats] = await Promise.all([
    fetch("/api/profile").then(r => r.json()),
    fetch("/api/stats").then(r => r.json())
  ]);
  console.log("Dashboard ready:", profile, stats);
}
