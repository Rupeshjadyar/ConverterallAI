Showing CSS properties
display
Layout Non-Animatable

Purpose: Specifies the rendering box type of an element and sets the formatting context for its children (block, inline, flex container, grid container, or completely hidden with none).

Values: block | inline | inline-block | flex | grid | none | contents Default: inline (or browser user-agent default) Related Lesson: 06. Display & Visibility
CSS
.container {
  display: flex;
  justify-content: space-between;
  align-items: center;
}
flex (Shorthand)
Flexbox Animatable

Purpose: Shorthand property for flex-grow, flex-shrink, and flex-basis. Determines how a flex item sizes itself and absorbs or gives up free space.

Common Values: flex: 1; (grow equally) | flex: 0 0 250px; (fixed width) | flex: auto; Related Lesson: 08. Flexbox Mastery
CSS
.main-content {
  flex: 1 1 auto; /* Grow to fill space, shrink if needed */
}
.sidebar {
  flex: 0 0 260px; /* Fixed 260px width, never shrink */
}
grid-template-columns
CSS Grid Animatable

Purpose: Defines the track sizing and column count of a CSS Grid container using fractions (fr), pixels, percentages, or the auto-fill pattern.

Related Lesson: 09. CSS Grid Masterclass
CSS
/* The Holy Grail responsive auto-wrapping grid */
.cards-grid {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 20px;
}
position
Positioning Non-Animatable

Purpose: Controls how an element is positioned in the document flow and establishes the positioning reference context for top, right, bottom, and left.

Values: static (default) | relative | absolute | fixed | sticky Related Lesson: 07. Positioning & Z-Index
CSS
.sticky-navbar {
  position: sticky;
  top: 0;
  z-index: 1000;
  background: var(--bg-card);
}
box-sizing
Box Model Essential Reset

Purpose: Defines how total width and height of an element are calculated. Setting to border-box causes padding and borders to be included inside the width, eliminating unwanted overflow.

Related Lesson: 05. The Box Model
CSS
*, *::before, *::after {
  box-sizing: border-box;
}
margin & padding
Spacing Animatable

Purpose: margin generates external space around an element (outside the border); padding generates internal whitespace within an element (inside the border).

CSS
.card {
  padding: 24px;       /* Top, Right, Bottom, Left */
  margin: 0 auto 30px; /* Center horizontally with auto */
}
background & background-color
Visual Animatable

Purpose: Sets background colors, gradients (linear-gradient, radial-gradient), and images on an element.

Related Lesson: 03. Colors & Backgrounds
CSS
.hero-banner {
  background: linear-gradient(135deg, #1e293b 0%, #0f172a 100%);
  color: #ffffff;
}
transition
Transitions Interactive

Purpose: Smoothly animates property changes over a specified duration rather than snapping immediately. Shorthand for: property, duration, timing-function, delay.

Related Lesson: 12. Transitions & Transforms
CSS
.btn {
  background: #38bdf8;
  transform: translateY(0);
  transition: all 0.25s cubic-bezier(0.4, 0, 0.2, 1);
}
.btn:hover {
  background: #0ea5e9;
  transform: translateY(-2px);
  box-shadow: 0 4px 12px rgba(14, 165, 233, 0.3);
}
CSS Custom Properties (--var) & calc()
Modern CSS Theming

Purpose: Reusable design tokens declared with --variable-name and consumed using var(--variable-name). Dynamically calculated with calc() and clamp().

Related Lesson: 14. CSS Variables, Calc & Clamp
CSS
:root {
  --brand-primary: #38bdf8;
  --sidebar-w: 260px;
}
.content {
  width: calc(100% - var(--sidebar-w));
  font-size: clamp(1rem, 2.5vw, 1.5rem);
}
