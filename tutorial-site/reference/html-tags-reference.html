<!DOCTYPE html>
Declaration Structure

Purpose: Tells the web browser that the document is written in modern HTML5. Must appear at the very first line of every HTML file before anything else to prevent legacy "quirks mode".

Closing: None (Prolog) Related Lesson: HTML Intro & Structure
HTML
<!DOCTYPE html>
<html lang="en">
  <!-- Page contents -->
</html>
<html>
Root Structure

Purpose: The root element of an HTML page. Every other tag in the document (except the DOCTYPE declaration) is a child or descendant of this element.

Closing: Required (</html>) Essential Attributes: lang="en" (specifies natural language for screen readers and SEO).
HTML
<html lang="en" dir="ltr">
  <head>...</head>
  <body>...</body>
</html>
<head>
Metadata Structure

Purpose: Container for metadata (information about the document that is not directly rendered on the screen) such as the page title, character set, stylesheets, and meta viewport settings.

Related Lesson: 12. Meta Tags & SEO
HTML
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>My Awesome Website</title>
  <link rel="stylesheet" href="style.css">
</head>
<body>
Visible Body Structure

Purpose: Represents the entire visible content of an HTML document. There can only be one <body> element per document.

HTML
<body>
  <header><h1>Welcome</h1></header>
  <main><p>Visible text on screen.</p></main>
  <footer>© 2026</footer>
</body>
<h1> through <h6>
Block Element Text

Purpose: Heading levels representing structural hierarchy, with <h1> as the main topic and <h6> as the lowest sub-heading. Always use exactly one <h1> per page for SEO and accessibility.

Related Lesson: 03. Headings & Text
HTML
<h1>Main Document Heading</h1>
<h2>Major Section Heading</h2>
<h3>Sub-section Heading</h3>
<p>
Block Element Text

Purpose: Represents a paragraph of text. Browsers automatically add vertical margin before and after paragraphs.

HTML
<p>This is a clear, readable paragraph of body text.</p>
<a> (Anchor)
Inline Element Navigation

Purpose: Creates a hyperlink to web pages, files, email addresses (mailto:), telephone numbers (tel:), or locations within the same page (#hash).

Key Attributes: href (destination URL), target="_blank" (open new tab), rel="noopener noreferrer" (security). Related Lesson: 04. Links & Navigation
HTML
<a href="about.html">Visit About Page</a>
<a href="https://example.com" target="_blank" rel="noopener noreferrer">External Site</a>
<a href="#contact-section">Jump to Contact Section</a>
<img>
Void / Self-Closing Media

Purpose: Embeds an image into the document. Mandatory alt attribute provides descriptive text for screen readers and search engines.

Key Attributes: src (path), alt (text description), loading="lazy" (performance), width, height. Related Lesson: 05. Images & Figures
HTML
<img src="images/sunset.jpg" alt="Vibrant golden sunset over calm ocean waves" width="800" height="450" loading="lazy">
<ul>, <ol>, <li> (Lists)
Block Elements Lists

Purpose: <ul> creates an unordered (bulleted) list. <ol> creates an ordered (numbered) list. <li> defines individual list items inside either list.

Related Lesson: 06. Lists & Navigation Bars
HTML
<ul>
  <li>HTML5 Fundamentals</li>
  <li>CSS3 Modern Styling</li>
</ul>

<ol start="1">
  <li>Install code editor</li>
  <li>Write index.html</li>
</ol>
<table> Suite
Tabular Data Tables

Purpose: Renders two-dimensional tabular data. Structured with <thead> (headers), <tbody> (data rows), <tr> (row), <th> (header cell), and <td> (data cell).

Related Lesson: 07. Tables & Data Grids
HTML
<table>
  <thead>
    <tr><th>Product</th><th>Price</th></tr>
  </thead>
  <tbody>
    <tr><td>Wireless Mouse</td><td>$25</td></tr>
  </tbody>
</table>
<form> & Input Controls
Interactive Form Forms

Purpose: Collects user data. <form> encapsulates inputs and coordinates submission. <input> provides text, email, number, checkbox, radio, file, and submit controls. Always pair with <label for="...">.

Related Lessons: 08. Forms • 09. Validation
HTML
<form action="/submit" method="POST">
  <label for="username">Username:</label>
  <input type="text" id="username" name="user" required minlength="3">

  <button type="submit">Save Account</button>
</form>
Semantic Layout Landmarks
Semantic HTML5 Structure

Purpose: Replaces generic <div> tags with descriptive, accessible landmark containers: <header>, <nav>, <main>, <section>, <article>, <aside>, and <footer>.

Related Lesson: 10. Semantic HTML
HTML
<header>Site Banner</header>
<nav>Main Navigation</nav>
<main>
  <article>Independent Article Content</article>
  <aside>Sidebar Notes</aside>
</main>
<footer>Footer Information</footer>
<video>, <audio>, <iframe>
Embedded Media Media

Purpose: Native multimedia playback without plugins. <video> and <audio> support controls, autoplay, and looping. <iframe> embeds another HTML page within the current document.

Related Lesson: 11. Audio, Video & iFrames
HTML
<video controls poster="preview.jpg" width="640">
  <source src="movie.mp4" type="video/mp4">
  Your browser does not support video playback.
</video>

<iframe srcdoc="<h1>Embedded Content</h1>" sandbox="allow-scripts"></iframe>
<details> & <summary>
Native Accordion Interactive

Purpose: Creates a native toggle disclosure widget without requiring any JavaScript! The contents are hidden until the user clicks the <summary> bar.

HTML
<details>
  <summary>Click to expand FAQ Answer</summary>
  <p>This hidden content reveals smoothly on click!</p>
</details>
<dialog>
Native Modal Interactive

Purpose: Represents a native modal or popup dialog. Provides built-in backdrop styling (::backdrop) and JavaScript methods dialog.showModal() and dialog.close() with automatic Escape key handling.

HTML
<dialog id="my-modal">
  <h3>Confirm Action</h3>
  <p>Are you sure you want to proceed?</p>
  <button onclick="document.getElementById('my-modal').close()">Close</button>
</dialog>
