Comprehensive Technical Glossary (A to Z)

The definitive encyclopedia of modern web development terms, protocols, and architectural concepts. Never leave this site to understand a term. Web development ke sabhi terms ki A se Z tak complete dictionary. Kisi bhi word ka matlab yahan dekhein.

A B C D E F G H I J L M O P Q R S T U V W X Z
A
API (Application Programming Interface)Web / Architecture

A set of rules, protocols, and tools that allows software applications to communicate with each other. In web development, web APIs allow client-side frontend code to send HTTP requests and receive structured JSON data from backend servers.

ARIA (Accessible Rich Internet Applications)HTML / Accessibility

A set of HTML attributes (e.g. aria-label, aria-hidden, role) that define ways to make web content and interactive UI components more accessible to people with disabilities using screen readers.

Async / AwaitJavaScript

Modern syntactic sugar built on top of JavaScript Promises. The async keyword designates a function as returning a Promise, while await pauses execution non-blockingly until a Promise settles.

B
Box ModelCSS

The foundational CSS layout model where every HTML element is treated as a rectangular box consisting of four concentric layers: Content, Padding (inner spacing), Border, and Margin (outer spacing).

Bubbling (Event Propagation)JavaScript / DOM

The phase in the DOM event lifecycle where an event starts at the target element that received the action and propagates upward through all its ancestors in the DOM tree towards the document root.

C
CallbackJavaScript

A function passed as an argument into another function, intended to be executed ("called back") at a later point in time or when an asynchronous operation completes.

ClosureJavaScript

The combination of a function bundled together with references to its surrounding lexical environment. A closure gives an inner function access to its outer function's scope even after the outer function has finished executing.

CORS (Cross-Origin Resource Sharing)Web / Security

A browser security mechanism that uses HTTP headers to tell browsers whether a web application running at one origin has permission to access resources from a server at a different origin.

D
DebouncePerformance Pattern

A programming pattern that limits the rate at which a function can fire. It delays execution until a certain amount of time has elapsed since the last time the function was invoked.

DOM (Document Object Model)Web Standards

An in-memory, object-oriented tree representation of the structured HTML document created by the browser. Allows programming languages like JavaScript to read, manipulate, add, or delete elements dynamically.

E
Event DelegationJavaScript / DOM

A technique where a single event listener is attached to a parent element rather than attaching individual listeners to multiple child elements, leveraging DOM event bubbling.

Event LoopJavaScript Engine

The background coordination engine in JavaScript runtimes that continuously monitors the Call Stack and moves callbacks from the Microtask and Task queues onto the stack once it becomes empty.

F
Flexbox (Flexible Box Layout)CSS

A one-dimensional CSS layout model that provides space distribution and powerful alignment capabilities along a main axis (row or column) and a cross axis.

G
Grid (CSS Grid Layout)CSS

A two-dimensional CSS layout system that enables developers to design complex web layouts structured into intersecting rows and columns without floats or positioning hacks.

H
HoistingJavaScript

The JavaScript engine behavior where variable and function declarations are allocated memory space during the creation phase of an execution context before any code is run.

HTTP & HTTPSNetworking

Hypertext Transfer Protocol. The underlying client-server protocol used to exchange hypermedia documents on the World Wide Web. HTTPS adds end-to-end TLS/SSL encryption for privacy and security.

I
IdempotenceArchitecture

A property of an HTTP method where executing the exact same request multiple times produces the identical side-effect on the server as executing it once (e.g. GET, PUT, DELETE).

J
JSON (JavaScript Object Notation)Data Format

A lightweight, language-agnostic text format for serializing structured data. Strict rules require double quotes around all keys and string values, with zero trailing commas allowed.

L
LocalStorageWeb Storage

A client-side synchronous key-value storage mechanism provided by the browser with approximately 5MB of capacity per origin that persists permanently until cleared by code or the user.

M
Media QueryCSS

A CSS module that allows styles to be applied selectively based on device characteristics, such as screen viewport width (min-width), orientation, or user color scheme preferences.

Microtask QueueJavaScript Engine

A high-priority execution queue reserved for Promise callbacks and queueMicrotask(). The Event Loop guarantees all microtasks are drained before any macrotask runs.

P
PromiseJavaScript

An object representing the eventual outcome of an asynchronous operation, existing in one of three states: pending, fulfilled, or rejected.

R
RegEx (Regular Expression)Pattern Matching

A specialized string of characters defining a search pattern, commonly used for validating input formats (like emails), searching documents, or performing complex text substitutions.

REST (Representational State Transfer)Architecture

A software architectural style for building network services using standard HTTP verbs (GET, POST, PUT, DELETE) to perform CRUD operations on resources identified by URIs.

S
Same-Origin Policy (SOP)Security

A critical web browser security mechanism that restricts a script loaded from one origin (combination of protocol, domain, and port) from interacting with resources from a different origin.

Semantic HTMLHTML

The practice of using HTML tags that convey the meaning of the content contained within them (e.g. <nav>, <article>, <footer>) rather than purely decorative <div> tags.

SpecificityCSS

The algorithm browsers use to determine which CSS rule applies to an element when multiple conflicting declarations match, calculated based on Inline styles > IDs > Classes/attributes > Elements.

T
ThrottlePerformance Pattern

A design pattern that ensures a function executes at most once every specified period of time, regardless of how many times the user fires the event (ideal for scroll triggers).

X
XSS (Cross-Site Scripting)Security

A security vulnerability that occurs when a web application includes untrusted user data in an output webpage without proper encoding or escaping, allowing malicious scripts to execute in victims' browsers.

Z
Z-IndexCSS

A CSS property that sets the Z-order (depth in 3D space) of a positioned element and its descendants, dictating which overlapping element renders in front.
