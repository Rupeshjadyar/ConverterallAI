1. Title Case a Sentence

Easy JavaScript

Write a function titleCase(str) that takes a string of words and returns the string with the first letter of each word capitalized and the remaining letters in lowercase.

Example: titleCase("sHoRt AnD sToUt") → "Short And Stout"
💡 Need a Hint?

Convert the entire string to lowercase first with .toLowerCase(), split the string into an array of words with .split(' '), map over each word capitalizing the first character with word[0].toUpperCase() + word.slice(1), and finally join the words back together with .join(' ').

✅ View Full Solution 
function titleCase(str) {
  return str
    .toLowerCase()
    .split(' ')
    .map(word => {
      if (!word) return '';
      return word.charAt(0).toUpperCase() + word.slice(1);
    })
    .join(' ');
}

// Tests:
console.log(titleCase("I'm a little tea pot")); // "I'm A Little Tea Pot"
console.log(titleCase("sHoRt AnD sToUt"));       // "Short And Stout"

3. Filterable Contact List with Instant Search

Medium DOM

Build an HTML input field and an unordered list of 10 contact names. Write JavaScript that listens to the input event and dynamically toggles the display of each list item so only matching contacts remain visible.

💡 Need a Hint?

Query all <li> elements with document.querySelectorAll('li'). On every input event, read e.target.value.toLowerCase(), loop through the list items, and set li.style.display = text.includes(search) ? 'block' : 'none'.

✅ View Full Solution 
const searchInput = document.getElementById("search-input");
const contactItems = document.querySelectorAll("#contacts-list li");

searchInput.addEventListener("input", function(e) {
  const query = e.target.value.toLowerCase().trim();

  contactItems.forEach(item => {
    const name = item.textContent.toLowerCase();
    if (name.includes(query)) {
      item.style.display = ""; // Reset to default display
    } else {
      item.style.display = "none";
    }
  });
});

4. Deep Clone an Object without External Libraries

Medium JavaScript

Write a recursive function deepClone(obj) that creates a truly independent deep copy of nested JavaScript objects and arrays without mutating the original structure.

💡 Need a Hint?

Check if the value is null or not an object (primitive). If primitive, return it as is. If an array, map over each element recursively. If an object, create a new object and recursively copy each key.

✅ View Full Solution 
function deepClone(obj) {
  // Primitives and null are copied by value
  if (obj === null || typeof obj !== "object") {
    return obj;
  }

  // Handle Arrays
  if (Array.isArray(obj)) {
    return obj.map(item => deepClone(item));
  }

  // Handle Objects
  const cloned = {};
  for (const key of Object.keys(obj)) {
    cloned[key] = deepClone(obj[key]);
  }
  return cloned;
}

// In modern standard JS: structuredClone(obj) is also natively available!

5. Infinite Scroll Loader with IntersectionObserver

Hard Web APIs / DOM

Implement a high-performance infinite scroll feeds viewer. When the sentinel <div id="sentinel"> scrolls into the browser viewport, load the next batch of 10 items asynchronously without attaching laggy scroll event listeners!

💡 Need a Hint?

Create an IntersectionObserver with a callback: new IntersectionObserver((entries) => { if (entries[0].isIntersecting) loadMore(); }) and observe the sentinel element at the bottom of the feed container.

✅ View Full Solution 
const feed = document.getElementById("feed-container");
const sentinel = document.getElementById("scroll-sentinel");
let page = 1;

const observer = new IntersectionObserver(async (entries) => {
  if (entries[0].isIntersecting) {
    console.log("Loading page:", page);
    await loadMoreItems(page);
    page++;
  }
}, { rootMargin: "200px" }); // Preload 200px before reaching bottom

observer.observe(sentinel);

async function loadMoreItems(pageNum) {
  for (let i = 1; i <= 5; i++) {
    const card = document.createElement("div");
    card.className = "post-card";
    card.textContent = `Article Post #${(pageNum - 1) * 5 + i}`;
    feed.insertBefore(card, sentinel);
  }
}
