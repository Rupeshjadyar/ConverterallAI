📚 Core Architectural Pillars
  • Keypad Grid Layout: A compact 4-column responsive grid with spans for 0 and = buttons.
  • State Machine: Tracking previousOperand, currentOperand, operation, and overwriteMode.
  • Float Safety: Avoiding classic 0.1 + 0.2 = 0.30000000000000004 bugs by rounding results cleanly with Math.round((num + Number.EPSILON) * 1e10) / 1e10.
  • Keyboard Accessibility: Listening to window.addEventListener('keydown', ...) to map number keys, operators, Enter, and Escape.
