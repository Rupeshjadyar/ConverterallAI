Tables: Organizing Tabular Data

Structure multi-dimensional datasets, pricing grids, and schedules with accessible tables, captions, and cell spans. Tabular data (jaise timetables, pricing plans aur spreadsheets) ko <table>, thead, tbody aur colspans ke saath structure karna seekhein.

📚 What You Will Learn
  • The proper semantic structure of an HTML table: <table>, <thead>, <tbody>, and <tfoot>.
  • The difference between rows (<tr>), header cells (<th>), and data cells (<td>).
  • Merging cells horizontally with colspan and vertically with rowspan.
  • Accessibility requirements: <caption> and the scope attribute.
  • Essential CSS table resets like border-collapse: collapse;.
  • Why tables must NEVER be used for page layouts (a notorious 1990s legacy mistake).
Prerequisites: Completion of 06. Lists.
🌟 Real-Life Analogy: The Train Station Departure Board

Walk into any central railway station and look up at the electronic departure board. At the very top is a clear title (<caption>): "Departures to Metro Regions". Below it is the header row (<thead>) with fixed columns: "Train #", "Destination", "Time", "Platform". Beneath are the rows of running trains (<tbody>). If a long freight train occupies two platforms simultaneously, it spans across rows (rowspan). That 2-dimensional grid is exactly what an HTML table represents! Railway station ke timetable display ki tarah sochiye. Upar board ka title hota hai (<caption>), headings hoti hain (Train No, Time, Platform - <thead>), aur har train ki row <tbody> mein hoti hai.

1. The Semantic Table Architecture

A professional HTML table is cleanly organized into three logical zones: a header, a body, and a summary footer:

Code Example 1: Standard Accessible Table

html
<table>
  <caption>Quarterly Employee Performance Metrics</caption>
  <thead>
    <tr>
      <th scope="col">Employee Name</th>
      <th scope="col">Role</th>
      <th scope="col">Projects Completed</th>
    </tr>
  </thead>
  <tbody>
    <tr>
      <td>Sophia Martinez</td>
      <td>Frontend Architect</td>
      <td>14</td>
    </tr>
    <tr>
      <td>Liam Johnson</td>
      <td>UI Designer</td>
      <td>18</td>
    </tr>
  </tbody>
  <tfoot>
    <tr>
      <th scope="row" colspan="2">Total Completed Projects</th>
      <td>32</td>
    </tr>
  </tfoot>
</table>
Key Tag Anatomy:
• <caption>: Accessible title read by screen readers; visually renders centered at the top.
• <thead>: Contains the column header labels (<th>).
• <tbody>: Contains the core dataset rows (<tr> and <td>).
• <tfoot>: Contains totals, averages, or summary calculations.
• scope="col" and scope="row": Explicitly tells screen readers which direction the header applies.

2. Merging Cells: colspan and rowspan

Just like "Merge Cells" in Microsoft Excel or Google Sheets, HTML allows table cells to span multiple columns or rows:

Code Example 2: Colspan and Rowspan in Action

html
<!-- colspan="2": Merges 2 columns horizontally across the row -->
<tr>
  <th colspan="2">Weekend Hours</th>
  <td>10:00 AM - 4:00 PM</td>
</tr>

<!-- rowspan="2": Merges 2 rows vertically down the column -->
<tr>
  <td rowspan="2">Morning Shift</td>
  <td>9:00 AM - 11:00 AM: Code Review</td>
</tr>
<tr>
  <!-- Notice: Only 1 td here because Morning Shift spans into this row! -->
  <td>11:00 AM - 1:00 PM: Feature Development</td>
</tr>
Crucial Arithmetic Rule: When using rowspan="2", the subsequent row must have ONE LESS <td> cell. If you don't remove it, the extra cell gets pushed out to the right, breaking your table layout!

3. Responsive Tables on Mobile Devices

Wide tables with 8 or 10 columns can easily break on mobile screens. The standard industry solution is wrapping the table in a container with horizontal scroll:

Code Example 3: The Responsive Wrapper Technique

html
<!-- Wrap any wide table in an overflow-x container -->
<div class="table-responsive" style="overflow-x: auto; width: 100%;">
  <table style="min-width: 600px;">
    <!-- Full table contents -->
  </table>
</div>
Why this works: On mobile screens, the user can swipe horizontally to scroll through table columns without distorting the rest of the website's layout.

Code Example 4: The <colgroup> and <col> Column Formatter

You can apply styling (like background colors or column widths) to an entire column at once:

html
<table>
  <colgroup>
    <col style="background-color: #f1f5f9; width: 40%;">
    <col style="width: 30%;">
    <col style="width: 30%;">
  </colgroup>
  <!-- rows follow -->
</table>
Efficiency: Instead of writing class="highlight" on 100 different <td> cells in the first column, you configure the column once in <colgroup>!

Code Example 5: Complete Schedule Grid with Mixed Spans

html
<table border="1">
  <caption>Weekly Workshop Timetable</caption>
  <tr>
    <th>Time</th>
    <th>Monday</th>
    <th>Wednesday</th>
    <th>Friday</th>
  </tr>
  <tr>
    <td>10:00 AM</td>
    <td rowspan="2">HTML5 Deep Dive (2 hrs)</td>
    <td>CSS Grid Lab</td>
    <td rowspan="2">Full Project Build (2 hrs)</td>
  </tr>
  <tr>
    <td>11:00 AM</td>
    <td>Flexbox Exercises</td>
  </tr>
  <tr>
    <td>12:00 PM</td>
    <td colspan="3" align="center">— Lunch Break for All —</td>
  </tr>
</table>
Structure Insight: Notice how the Lunch Break row uses colspan="3" to span all three workshop days effortlessly.

Code Example 6: Querying Table Data with JavaScript

javascript
// Read table row data programmatically
const rows = document.querySelectorAll("tbody tr");
const dataset = [];

rows.forEach(row => {
  const cells = row.querySelectorAll("td");
  dataset.push({
    plan: cells[0].textContent,
    storage: cells[1].textContent,
    price: cells[2].textContent
  });
});

console.table(dataset);
Key Integration: JavaScript can extract structured arrays of objects directly from semantic HTML tables in seconds.
⚠ Common Beginner Mistakes
  • Using tables for page layout: In 1998, developers used tables to build sidebars and headers. In modern web development, this is strictly forbidden! Use CSS Flexbox and CSS Grid for layout. Use <table> strictly for tabular datasets.
  • Forgetting border-collapse: collapse;: By default, browsers give tables ugly double borders with strange gaps between cells. Always add border-collapse: collapse; in CSS.
  • Miscounting cells during rowspans: If a row has 4 columns and one cell has colspan="2", that row should only have 3 cell elements total (2 + 1 + 1 = 4).
💡 Pro Tips
  • Always right-align numerical columns (currency, metrics, percentages) using text-align: right; — this makes numbers significantly easier for human eyes to compare down a column.
  • Always provide <caption> — screen readers use the caption as an announcement hook when navigating between multiple tables on a financial or statistical page.
🔄 Quick Recap
  • <table> organizes 2D tabular datasets (never page layouts).
  • Structure with <caption>, <thead>, <tbody>, and <tfoot>.
  • <tr> = table row; <th> = header cell; <td> = data cell.
  • colspan merges columns horizontally; rowspan merges rows vertically.
  • Use scope="col" and scope="row" for accessibility compliance.
  • Use border-collapse: collapse; in CSS for clean, crisp single-pixel borders.

Practice Exercises

Exercise 1 (Easy): Identify Header vs Data Cells Easy

What is the semantic difference between <th> and <td>?

Hint: Think about which one labels a column and which one holds row values.
Solution: <th> represents a Table Header cell (bold, centered, announced as a header by screen readers). <td> represents a standard Table Data cell.
Exercise 2 (Medium): Horizontal Colspan Medium

You have a 4-column table. Write the markup for a single row where one cell spans across all 4 columns with the text "No records found".

Hint: Use colspan=4 inside a tr.
Solution:
<tr><td colspan="4" align="center">No records found</td></tr>
Exercise 3 (Hard): Fixing the Broken Rowspan Arithmetic Hard

Spot and correct the bug in this 2-column table:

<tr>
  <td rowspan="2">Category</td>
  <td>Item A</td>
</tr>
<tr>
  <td>Extra Cell</td>
  <td>Item B</td>
</tr>
Hint: How many columns does row 2 have when Category spans into it?
Solution: Because "Category" spans vertically into the second row, row 2 already has its first column occupied! Having two cells (Extra Cell + Item B) in row 2 creates 3 total columns, blowing out the grid. Delete "Extra Cell":
<tr>
  <td rowspan="2">Category</td>
  <td>Item A</td>
</tr>
<tr>
  <td>Item B</td>
</tr>
