Images, Figures and Captions

Embed graphics, optimize layout stability, write accessible alt text, and package media semantically with figures. Images ko sahi tarike se embed karna, layout shift (CLS) rokna aur <figure> ke sath captions lagana seekhein.

🌟 Real-Life Analogy: The Museum Exhibit Plaque

Imagine walking through a museum art gallery. Every painting on the wall is placed in a protective frame (<figure>). Next to the painting is a brass plaque describing the title, artist, and year of creation (<figcaption>). If a visitor who is visually impaired approaches the exhibit with a tour guide, the guide verbally describes what the painting depicts — that verbal description is the alt text! Without the plaque and guide, the artwork is mysterious and inaccessible. Ek museum ki tarah sochiye. Deewar par lagi tasveer ek frame mein hoti hai (<figure>). Uske neeche lagi peetal ki plate jisme tasveer ka naam likha hota hai woh hai <figcaption>. Aur kisi blind visitor ke liye guide jo tasveer bol kar samjhata hai, woh hai alt text.

1. The <img> Element and Core Attributes

The <img> tag is a void element — it does not wrap text and never has a closing tag. It embeds an image by pointing to its file location:

Code Example 1: Standard Accessible Image Markup

html
<img src="images/team-meeting.jpg"
     alt="Five engineers collaborating around a laptop discussing architecture"
     width="800"
     height="450"
     loading="lazy">
Attribute Analysis:
• src: The relative path or URL to the image file.
• alt: Alternative text read by screen readers and displayed if the file is missing.
• width and height: Aspect ratio hints for the browser rendering engine.
• loading="lazy": Tells the browser not to download the image until the user scrolls near it.

2. Why alt Text is Non-Negotiable

The alt attribute serves three critical functions:

  1. Screen Readers: Over 2 billion people worldwide live with vision impairments. Screen readers speak the alt text aloud so users understand the visual information.
  2. Broken Connections: If the user is on a slow connection or the image fails to load (404), the browser displays the alt text in place of the missing picture.
  3. Search Engine Optimization: Google image bots cannot "see" images directly; they read your alt descriptions to index and rank your content.

Code Example 2: Good vs Bad Alt Text

html
<!-- TERRIBLE: Missing alt completely (Violates WCAG rules!) -->
<img src="cat.jpg">

<!-- POOR: Redundant filler words -->
<img src="cat.jpg" alt="Picture of a cat photo image">

<!-- EXCELLENT: Concise, descriptive context -->
<img src="cat.jpg" alt="Orange tabby kitten sleeping in a sunny windowsill">

<!-- PURELY DECORATIVE: Use empty alt="" so screen readers skip it cleanly -->
<img src="decorative-divider.svg" alt="" role="presentation">
Screen Reader Tip: Never start alt text with "Image of..." or "Picture of...". Screen readers already announce "Graphic:" before reading the alt text!

3. Semantic Media Packaging with <figure> & <figcaption>

Before HTML5, developers wrapped images in random <div> tags and styled captions using paragraph classes. HTML5 introduced two dedicated semantic elements:

  • <figure>: An independent content unit (photos, diagrams, code listings, charts) that can be moved to another part of the document without altering the flow.
  • <figcaption>: The visible explanatory caption directly linked to that figure.

Code Example 3: Proper Figure Structure

html
<figure>
  <img src="charts/revenue-q4.svg"
       alt="Bar chart showing 42% revenue growth in fourth quarter"
       width="600"
       height="300">
  <figcaption>Figure 4: Annual revenue growth trajectory (2025–2026)</figcaption>
</figure>
Hierarchy Rule: <figcaption> must be either the very first child or the very last child inside <figure>.

Code Example 4: Preventing Cumulative Layout Shift (CLS)

Have you ever tried reading an article on your phone, and suddenly the text jumped 5 inches down the screen because a photo loaded? That frustrating bug is called Cumulative Layout Shift (CLS):

html
<!-- BAD: Browser has no idea how tall the image will be until download finishes! -->
<img src="banner.jpg" alt="Hero Banner">

<!-- GOOD: Browser reserves exact aspect ratio box immediately before image downloads! -->
<img src="banner.jpg" alt="Hero Banner" width="1200" height="400">
How Browsers Reserve Space: Providing width and height attributes tells the browser the aspect ratio (1200 / 400 = 3:1). The browser calculates the placeholder height instantly, preventing any text jumping!

Code Example 5: Web Image Formats Comparison

plaintext
Format     Best Used For                         Key Advantage
-------------------------------------------------------------------------------
SVG        Logos, icons, geometric diagrams       Infinitely scalable, crystal clear at any zoom
WebP       Modern web photos & UI graphics        30% smaller than JPEG with superior quality
PNG        Screenshots, transparent graphics      Lossless clarity with alpha transparency
JPEG/JPG   Photographs with millions of colors    Universal legacy browser compatibility
Golden Rule: For logos and UI icons, always prefer SVG. For photographs, use WebP (with JPEG as legacy fallback).

Code Example 6: Inspecting Image Loading States with JavaScript

JavaScript can detect when an image has finished loading or failed to download:

javascript
const img = document.querySelector("img");

img.addEventListener("load", function() {
  console.log("Image loaded cleanly!");
  console.log("Natural Dimensions: " + this.naturalWidth + "x" + this.naturalHeight + "px");
});

img.addEventListener("error", function() {
  console.error("Failed to load image. Path is invalid or network is offline.");
  this.alt = "Image failed to load";
});
Key Properties: naturalWidth and naturalHeight give you the exact raw pixel dimensions of the image file on disk.
⚠ Common Beginner Mistakes
  • Treating <img> as a container tag: Never write <img src="..."></img>! <img> is a void element with no closing tag.
  • Writing useless alt text: Writing alt="image" or alt="photo" gives zero value to someone using a screen reader. Describe what is actually happening in the scene.
  • Uploading gigantic 10MB camera files: Always resize and compress photos before putting them on a website. Large images waste user bandwidth and slow down your site.
💡 Pro Tips
  • Always add loading="lazy" to images that are below the initial screen fold so the browser doesn't waste time downloading them on initial page load.
  • In CSS, add img { max-width: 100%; height: auto; } to your global stylesheet — this makes all images effortlessly responsive across mobile phones!
🔄 Quick Recap
  • <img> is a void element requiring src and alt.
  • alt text is mandatory for accessibility (WCAG), SEO, and fallback rendering.
  • Always specify width and height to eliminate Cumulative Layout Shift (CLS).
  • Wrap diagrams and illustrative photos in <figure> and <figcaption>.
  • Use loading="lazy" for below-the-fold images to optimize load performance.
  • Use SVG for logos/icons and WebP for photos.

Practice Exercises

Exercise 1 (Easy): Identify the Missing Void Attribute Easy

An auditor looks at this markup: <img src="hero.jpg"> and flags a WCAG accessibility violation. What essential attribute is missing?

Hint: How will a visually impaired user know what the image shows?
Solution: The alt attribute is completely missing! It must have a descriptive alternative text: <img src="hero.jpg" alt="Description of hero graphic">.
Exercise 2 (Medium): Preventing Layout Shift Medium

How do you modify <img src="avatar.png" alt="User avatar"> to prevent the page from shifting layout when the 150x150 avatar image loads?

Hint: Provide the raw pixel dimensions.
Solution: Add width="150" height="150":
<img src="avatar.png" alt="User avatar" width="150" height="150">
Exercise 3 (Hard): Building a Complete Figure Package Hard

Write the complete HTML markup for an architectural diagram: wrap it in a figure, embed blueprint.svg with alt text "Floor plan of two-bedroom apartment", specify 800x600 dimensions, and add a figcaption reading "Diagram 1: Proposed Ground Floor Layout".

Hint: figcaption lives inside figure.
Solution:
<figure>
  <img src="blueprint.svg" alt="Floor plan of two-bedroom apartment" width="800" height="600">
  <figcaption>Diagram 1: Proposed Ground Floor Layout</figcaption>
</figure>
