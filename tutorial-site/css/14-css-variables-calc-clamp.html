1. Declaring & Consuming CSS Variables

CSS Custom Properties always start with two hyphens (--). They are case-sensitive and inherit down the DOM tree just like standard font properties:

Code Example 1: Global Variables in :root

css
/* :root matches the  element, giving global scope to variables */
:root {
  --color-primary: #2563eb;
  --color-primary-hover: #1d4ed8;
  --color-surface: #ffffff;
  --color-text: #0f172a;
  --radius-md: 8px;
  --space-unit: 16px;
}

/* Consuming the variables using var() */
.card {
  background-color: var(--color-surface);
  color: var(--color-text);
  border-radius: var(--radius-md);
  padding: var(--space-unit);
  border: 1px solid #e2e8f0;
}

.card-btn {
  background-color: var(--color-primary);
  /* Fallback: if --radius-md isn't defined, use 4px */
  border-radius: var(--radius-md, 4px);
}

2. Instant Dark Theme Architecture

With CSS variables, creating a complete Dark/Light mode theme engine requires changing just a handful of color tokens on body[data-theme="dark"]:

Code Example 2: The Modern Token-Swapping Theme Engine

css
:root {
  --bg-app: #f8fafc;
  --bg-card: #ffffff;
  --text-main: #0f172a;
  --border-app: #e2e8f0;
}

/* When the user toggles dark mode, we just override the variable tokens! */
[data-theme="dark"] {
  --bg-app: #0f172a;
  --bg-card: #1e293b;
  --text-main: #f8fafc;
  --border-app: #334155;
}

/* Notice that our components NEVER need duplicate dark mode rules! */
body {
  background-color: var(--bg-app);
  color: var(--text-main);
  transition: background-color 0.3s ease, color 0.3s ease;
}

.panel {
  background-color: var(--bg-card);
  border: 1px solid var(--border-app);
}

3. Dynamic Calculations with calc()

The calc() function allows you to perform basic arithmetic operations (+, -, *, /) directly inside CSS, mixing completely different units together!

The Fatal Syntax Trap: In calc(), the + and - operators MUST have spaces around them! Writing calc(100% - 20px) works, but calc(100%-20px) fails as an invalid expression because the browser interprets -20px as a negative number.

Code Example 3: Mixing Viewport and Fixed Units with calc()

css
:root {
  --nav-height: 60px;
}

/* Full screen height minus the fixed sticky navbar */
.main-layout {
  min-height: calc(100vh - var(--nav-height));
}

/* Responsive sidebar with exact remaining column width */
.sidebar {
  width: 260px;
}
.content-area {
  width: calc(100% - 260px);
}

4. Modern Mathematical Functions: min(), max(), clamp()

Modern CSS math eliminates cumbersome JavaScript resize listeners and multiple media queries:

Code Example 4: min(), max(), and clamp()

css
/* 1. min(a, b): Picks whichever value is SMALLER at this exact moment */
.responsive-modal {
  /* On mobile takes 90% width; on desktop caps strictly at 500px */
  width: min(90%, 500px);
}

/* 2. max(a, b): Picks whichever value is LARGER at this exact moment */
.banner {
  /* Never smaller than 300px, but expands with viewport */
  height: max(300px, 40vh);
}

/* 3. clamp(MIN, PREFERRED, MAX): The Ultimate Value Lock */
.fluid-heading {
  /* Never smaller than 1.5rem, never bigger than 3rem, scales with 4vw */
  font-size: clamp(1.5rem, 4vw, 3rem);
}

/* Fluid responsive padding */
.container {
  padding: clamp(1rem, 5vw, 4rem);
}

5. Scoped Component Variables

Variables don't just belong in :root. You can declare variables directly on specific components to customize variants cleanly without selector specificity bloat:

Code Example 5: Component-Level Scoped Variables

css
/* Base Button Token Contract */
.btn {
  --btn-bg: #e2e8f0;
  --btn-color: #0f172a;
  
  background-color: var(--btn-bg);
  color: var(--btn-color);
  padding: 10px 20px;
  border-radius: 6px;
  border: none;
}

/* Modifiers just override the local tokens! */
.btn-primary {
  --btn-bg: #2563eb;
  --btn-color: #ffffff;
}

.btn-danger {
  --btn-bg: #ef4444;
  --btn-color: #ffffff;
}

⚠ Common Beginner Mistakes
  • Missing spaces around calc() operators: calc(100%-40px) causes the entire rule to be ignored by the browser. Always write calc(100% - 40px).
  • Case sensitivity bugs: --brandColor and --brandcolor are two completely separate variables. Standardize on lowercase kebab-case (e.g. --brand-color).
  • Forgetting var() wrapper: Writing color: --brand-color; does nothing. You must wrap the variable name in the var(...) function: color: var(--brand-color);.
  • Using CSS variables in media query parameters: You cannot write @media (min-width: var(--breakpoint-tablet)). CSS variables are not evaluated inside media query conditions.
💡 Pro Tips from Senior Engineers
  • Inspect & modify live in DevTools: Variables show up under :root in the Chrome DevTools Styles pane. You can click the color swatch to live-test colors across your entire site in real time!
  • Pass variables into SVG: Setting fill: var(--icon-color, currentColor); on SVG vector icons lets them adapt dynamically to their surrounding text color automatically.
  • Manipulate variables via JavaScript: You can read and write variables in vanilla JS via document.documentElement.style.setProperty('--brand-color', '#ff0000'); for interactive user customizers!
⚡ Quick Recap
  • CSS Variables begin with -- and are consumed via var(--name, fallback).
  • Global tokens are declared inside :root.
  • Dark mode is achieved by swapping variable values on [data-theme="dark"].
  • calc() allows mixing units (e.g. vh and px); operators must have whitespace around them.
  • clamp(min, preferred, max) locks values between bounds while scaling fluidly.
  • width: min(90%, 600px) is a clean one-liner for responsive dialogs.

7. Practice Coding Exercises

Exercise 1 (Easy): Consuming a Variable with Fallback Easy

Write the CSS declaration for a button's background-color that consumes the custom property --accent-color, but falls back to #2563eb if the variable is not defined.

Hint: var(--property, fallback).
Solution:
background-color: var(--accent-color, #2563eb);
Exercise 2 (Medium): Full-Height Minus Sticky Header Medium

You have a top navigation bar of 70px. Write the CSS declaration using calc() to ensure a hero section takes up exactly the rest of the visible screen height.

Hint: min-height: calc(100vh - 70px);
Solution:
.hero-section {
  min-height: calc(100vh - 70px);
}
Exercise 3 (Hard): Fluid Container Spacing Hard

Write a single CSS declaration using clamp() to set horizontal padding that never drops below 16px, never exceeds 64px, and scales with 5% of viewport width.

Hint: padding-inline: clamp(16px, 5vw, 64px);
Solution:
padding-inline: clamp(16px, 5vw, 64px);
