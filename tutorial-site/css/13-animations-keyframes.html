1. Defining Timelines with @keyframes

The @keyframes rule defines the visual poses across an animation timeline using percentages (0% represents the start, 100% represents the conclusion):

Code Example 1: The @keyframes Syntax

css
/* 1. Define the named timeline */
@keyframes pulseGlow {
  0% {
    transform: scale(0.95);
    box-shadow: 0 0 0 0 rgba(37, 99, 235, 0.7);
  }
  70% {
    transform: scale(1);
    box-shadow: 0 0 0 12px rgba(37, 99, 235, 0);
  }
  100% {
    transform: scale(0.95);
    box-shadow: 0 0 0 0 rgba(37, 99, 235, 0);
  }
}

/* 2. Bind the timeline to an HTML element */
.live-beacon {
  width: 14px;
  height: 14px;
  background-color: #2563eb;
  border-radius: 50%;
  animation: pulseGlow 2s infinite ease-in-out;
}

2. The 8 Animation Properties & Shorthand

CSS provides 8 granular controls for animation behavior:

Property Purpose Common Values
animation-name Identifies the @keyframes rule spin, fadeIn, shimmer
animation-duration Time taken to complete one full cycle 0.5s, 1200ms
animation-timing-function Acceleration curve linear, ease, cubic-bezier()
animation-delay Wait time before animation begins 0s, 0.3s, -0.5s (starts midway!)
animation-iteration-count How many times the animation repeats 1, 3, infinite
animation-direction Playback direction normal, reverse, alternate
animation-fill-mode Style retention before/after execution none, forwards, backwards, both
animation-play-state Pause or resume motion running, paused

3. The Snapping Trap: animation-fill-mode: forwards

By default, when a one-shot animation finishes (100%), the element abruptly snaps back to its pre-animation styling! To instruct the browser to retain the final 100% keyframe appearance, you must specify forwards:

Code Example 2: Fade-In Entrance with `forwards`

css
@keyframes slideUpFade {
  from {
    opacity: 0;
    transform: translateY(20px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

.modal-dialog {
  /* Crucial: 'forwards' keeps the modal at opacity: 1 and translateY(0) */
  animation: slideUpFade 0.3s cubic-bezier(0.16, 1, 0.3, 1) forwards;
}

4. Real-World Recipe: The Infinite Circular Loading Spinner

A pure CSS spinner requires zero external images or heavy GIFs:

Code Example 3: Pure CSS Loading Spinner

css
@keyframes spin {
  to {
    transform: rotate(360deg);
  }
}

.spinner {
  width: 32px;
  height: 32px;
  border: 3px solid #e2e8f0;          /* Subtle light track */
  border-top-color: #2563eb;          /* Vibrant active spinning tip */
  border-radius: 50%;
  animation: spin 0.8s linear infinite; /* Smooth robotic infinite spin */
}

5. Real-World Recipe: Skeleton Shimmer Loading Placeholder

Top tech companies use shimmering skeleton gray cards while fetching data to make loading feel twice as fast:

Code Example 4: Skeleton Screen Shimmer

css
@keyframes shimmer {
  0% {
    background-position: -200% 0;
  }
  100% {
    background-position: 200% 0;
  }
}

.skeleton-box {
  height: 20px;
  border-radius: 4px;
  background: linear-gradient(
    90deg,
    #e2e8f0 25%,
    #f8fafc 50%,
    #e2e8f0 75%
  );
  background-size: 200% 100%;
  animation: shimmer 1.5s infinite linear;
}

6. Pausing Animations on Hover

Enhance user control by freezing marquee tickers or spinning logos whenever a user points their cursor at them:

Code Example 5: Pausing Play State on Hover

css
.news-ticker-track {
  display: flex;
  animation: scrollNews 20s linear infinite;
}

/* Pause the scrolling so the user can click or read comfortably */
.news-ticker-track:hover {
  animation-play-state: paused;
}

⚠ Common Beginner Mistakes
  • Omitting animation-fill-mode: forwards: One-shot modal entrances suddenly flicker and reset back to invisible the microsecond the animation completes.
  • Continuous heavy CPU animations: Running dozens of infinite non-stop animations drains mobile phone batteries rapidly. Always pause off-screen animations.
  • Animating layout dimensions: Never animate width or height inside @keyframes. Use transform: scale() for hardware acceleration.
  • Missing the @ in @keyframes: Writing keyframes myAnim { ... } is invalid CSS and fails silently.
💡 Pro Tips from Senior Engineers
  • Negative animation-delay: Setting animation-delay: -0.5s starts the animation instantly as if it had already been running for half a second. Perfect for staggered multi-dot spinners!
  • Use alternate direction for natural oscillation: animation-direction: alternate plays 0% → 100% and then reverses 100% → 0%, creating seamless back-and-forth pendulum motions.
  • Respect prefers-reduced-motion: Always disable high-movement animations for users who request calm interfaces in their system settings.
⚡ Quick Recap
  • @keyframes defines chronological poses using percentages from 0% to 100%.
  • Animations run autonomously without needing user triggers like :hover.
  • animation-fill-mode: forwards retains final keyframe styles permanently.
  • animation-iteration-count: infinite runs continuous loops for spinners.
  • animation-play-state: paused freezes motion dynamically on cursor hover.
  • Stick to transform and opacity to prevent mobile frame stutters.

Exercise 1 (Easy): Infinite Spinner Shorthand Easy

Given a keyframe named spin, write the shorthand CSS animation property to run it continuously over 1 second at a constant robotic speed.

Hint: animation: spin 1s linear infinite;

Exercise 2 (Medium): Prevent Animation Snap-Back Medium

A slide-in banner animates onto the screen over 0.5s, but instantly disappears when the animation finishes. Which property and value fixes this issue?

Hint: animation-fill-mode forwards.
Solution:
animation-fill-mode: forwards;
Exercise 3 (Hard): Pendulum Oscillating Motion Hard

How do you configure an animation so that instead of restarting abruptly from 0% when reaching 100%, it plays backwards from 100% back to 0% in an infinite loop?

Hint: animation-direction: alternate;
Solution:
animation-direction: alternate; animation-iteration-count: infinite;
