CSS Grid: 2-Dimensional Layout Architecture

Orchestrate rows and columns simultaneously. Master fr units, repeat, minmax, and responsive auto-fit grids. CSS Grid ke sath 2D layouts (rows aur columns ek sath) design karein. Fr units, repeat, minmax aur auto-fit seekhein.

  • The flexible fraction unit (fr) and how it distributes space.
  • The Holy Grail of responsive cards: repeat(auto-fit, minmax(280px, 1fr)) without a single media query!
  • Item placement and spanning using grid-column: span 2 and grid lines.

1. Defining Columns, Rows & The Fraction Unit (fr)

Applying display: grid activates the CSS Grid formatting engine. You establish the column tracks using grid-template-columns.

CSS Grid introduced the revolutionary fraction unit (fr), which represents a fraction of the available free space remaining in the container:

Code Example 1: Basic 3-Column Grid

css
.dashboard-grid {
  display: grid;
  /* 3 columns: Left sidebar 260px, Main center takes 3 parts, Right takes 1 part */
  grid-template-columns: 260px 3fr 1fr;
  grid-template-rows: auto;
  gap: 24px;
}
The browser subtracts the fixed 260px sidebar and the two 24px gaps from total container width, then divides the remaining pixels into 4 equal slices: 3 slices go to the center column, and 1 slice goes to the right column!

2. Clean Syntax with repeat() and minmax()

Instead of writing 1fr 1fr 1fr 1fr, use the repeat() function. Combine it with minmax(min, max) to enforce lower and upper bounds:

Code Example 2: Repeat and Minmax Functions

css
/* 4 equal columns */
.four-cols {
  grid-template-columns: repeat(4, 1fr);
}

/* 3 columns where each column never shrinks below 200px */
.responsive-cols {
  grid-template-columns: repeat(3, minmax(200px, 1fr));
}

3. The Ultimate Responsive Card Grid (Zero Media Queries!)

This is arguably the most famous single line of modern CSS code. It automatically creates as many columns as will fit on any screen size, wrapping gracefully from mobile to 4K monitors without writing a single @media query:

Code Example 3: The Magic Responsive Auto-Fit Grid

css
.product-grid {
  display: grid;
  /* The Magic Formula: */
  grid-template-columns: repeat(auto-fit, minmax(280px, 1fr));
  gap: 20px;
}
How It Works:
• auto-fit: Tells the browser to cram as many columns as possible into each row.
• minmax(280px, 1fr): Each column must be at least 280px wide. If extra space remains on the row, they stretch equally (1fr) to fill the width edge-to-edge.

4. Spanning Rows and Columns

Individual grid items can span across multiple rows or columns. You can specify exact grid line numbers (1-indexed) or use the intuitive span keyword:

Code Example 4: Hero Feature Card Spanning

css
.article-grid {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 16px;
}

/* The first featured article spans 2 columns wide */
.featured-article {
  grid-column: span 2; /* Occupies 2 columns */
}

/* Or using grid line indices (Line 1 to Line 3) */
.featured-hero {
  grid-column: 1 / 3;
  grid-row: 1 / 3; /* Spans 2 rows deep as well! */
}

5. Visual Layout with grid-template-areas

CSS Grid allows you to literally "draw" your page layout directly in CSS using named text strings. It is remarkably self-documenting and easy to read:

Code Example 5: Visual Page Layout via Named Areas

css
.page-layout {
  display: grid;
  grid-template-columns: 240px 1fr 200px;
  grid-template-rows: 60px 1fr 60px;
  grid-template-areas:
    "header  header  header"
    "sidebar main    ads"
    "footer  footer  footer";
  min-height: 100vh;
  gap: 12px;
}

header  { grid-area: header; }
aside   { grid-area: sidebar; }
main    { grid-area: main; }
.ads    { grid-area: ads; }
footer  { grid-area: footer; }

6. Flexbox vs Grid: Which One to Choose?

Criterion Use Flexbox Use CSS Grid
Dimension 1-Dimensional (Row OR Column) 2-Dimensional (Rows AND Columns simultaneously)
Design Mindset Content-first: Items determine size; container flows around them Layout-first: Rigorous blueprint grid is defined; items drop into cells
Best Applications Navbars, button groups, icon+label alignment, form field controls Page shell layouts, product card galleries, photo mosaics, dashboard metrics

⚠ Common Beginner Mistakes
  • Forgetting that Grid Line numbers start at 1: In CSS Grid, lines start at 1, not 0. A 3-column grid has 4 vertical grid lines (1, 2, 3, 4).
  • Confusing auto-fill and auto-fit: auto-fill creates empty ghost tracks if there aren't enough items, whereas auto-fit collapses empty tracks to allow existing items to expand.
  • Using fixed pixel widths inside grids: Setting width: 300px on grid items fights against 1fr sizing and destroys responsiveness. Let the grid tracks manage item widths!
  • Writing media queries for basic card decks: Don't write 5 breakpoint queries when repeat(auto-fit, minmax(280px, 1fr)) handles all screen sizes automatically.
💡 Pro Tips from Senior Engineers
  • Chrome DevTools Grid Overlay: Open DevTools → Elements tab → click the tiny grid badge next to your container. DevTools will render dotted grid lines with exact line numbers on your screen!
  • Place items in the same cell for overlapping hero banners: You can place both a background image and text on grid-column: 1 / -1; grid-row: 1 / -1; to create clean layered hero banners without absolute positioning.
  • Combine Flexbox AND Grid: Senior developers use CSS Grid for the master page shell and card arrays, and Flexbox for micro-alignments inside the individual cards (buttons, badges, icons).
⚡ Quick Recap
  • CSS Grid handles 2D layouts (rows and columns) simultaneously.
  • fr represents a fraction of remaining free space.
  • repeat(auto-fit, minmax(280px, 1fr)) creates responsive card galleries without media queries.
  • Grid lines are 1-indexed; grid-column: 1 / 3 spans across columns 1 and 2.
  • grid-template-areas visualizes complete layouts using ASCII text templates.
  • Use Grid for macro page structures; use Flexbox for micro UI components.

8. Practice Coding Exercises

Exercise 1 (Easy): 3 Equal-Width Columns Easy

Write the CSS rule for a .gallery container that displays 3 identical flexible columns with a 20px gap using the repeat() function.

Hint: Combine display: grid, repeat(3, 1fr), and gap: 20px.
Solution:
.gallery {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 20px;
}
Exercise 2 (Medium): Responsive Magazine Layout Medium

In a 4-column article grid, write the CSS to make the leading .hero-card occupy the first 3 columns wide and the first 2 rows high.

Hint: Use grid-column: span 3 and grid-row: span 2.
Solution:
.hero-card {
  grid-column: span 3;
  grid-row: span 2;
}
/* Or line syntax: grid-column: 1 / 4; grid-row: 1 / 3; */
Exercise 3 (Hard): The Zero-Query Grid Recipe Hard

Write the exact CSS property and value that automatically fills a grid with columns that never shrink below 220px, but stretch equally to consume all remaining row width.

Hint: repeat(auto-fit, minmax(...)).
Solution:
grid-template-columns: repeat(auto-fit, minmax(220px, 1fr));
