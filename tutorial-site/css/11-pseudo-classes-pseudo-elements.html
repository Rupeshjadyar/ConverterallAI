1. The Fundamental Distinction: Single (:) vs Double (::) Colon

Type Syntax What it targets Examples
Pseudo-Class Single colon : An existing element in a specific dynamic state or DOM position :hover, :focus-visible, :nth-child(2), :checked
Pseudo-Element Double colon :: A virtual sub-part or generated fragment of an element ::before, ::after, ::selection, ::placeholder

2. Interaction States & Accessible Focus Rings

Never remove focus rings with outline: none without providing an accessible replacement! Modern browsers provide :focus-visible, which displays focus rings only for keyboard tab navigation while suppressing them on mouse clicks:

Code Example 1: Accessible Interaction States

css
.primary-btn {
  background-color: #2563eb;
  color: #ffffff;
  padding: 10px 20px;
  border-radius: 6px;
  border: none;
  cursor: pointer;
  transition: background-color 0.15s ease, transform 0.1s ease;
}

/* Mouse cursor hovering */
.primary-btn:hover {
  background-color: #1d4ed8;
}

/* Moment of clicking down */
.primary-btn:active {
  transform: scale(0.97);
}

/* Keyboard Tab Navigation Focus (High Accessibility!) */
.primary-btn:focus-visible {
  outline: 3px solid #60a5fa;
  outline-offset: 3px;
}

3. Structural & Form Pseudo-Classes

Style elements based on their position in parent containers or their form input state without cluttering HTML with extra classes:

Code Example 2: Zebra Stripes & Disabled Inputs

css
/* Zebra striping table rows */
tbody tr:nth-child(even) {
  background-color: #f8fafc;
}

/* Highlight the very first paragraph in an article */
article p:first-of-type {
  font-size: 1.2rem;
  font-weight: 500;
  color: #1e293b;
}

/* Style checkboxes when selected */
input[type="checkbox"]:checked + label {
  font-weight: 700;
  color: #16a34a;
}

/* Disabled button appearance */
button:disabled {
  opacity: 0.5;
  cursor: not-allowed;
}

4. The Power of ::before & ::after

Pseudo-elements let you insert decorative flourishes, notification dots, tooltips, and badges purely from CSS.

The Golden Rule: A pseudo-element WILL NOT RENDER unless you declare the content: "" property! Even if empty, content is mandatory.

Code Example 3: Live Pulsing Online Status Indicator

css
.user-avatar {
  position: relative; /* Anchor for pseudo-element */
  width: 50px;
  height: 50px;
  border-radius: 50%;
}

/* Green online status dot generated purely in CSS */
.user-avatar.is-online::after {
  content: ""; /* REQUIRED! */
  position: absolute;
  bottom: 2px;
  right: 2px;
  width: 12px;
  height: 12px;
  background-color: #22c55e;
  border: 2px solid #ffffff;
  border-radius: 50%;
}

5. The Revolutionary :has() Parent Selector

For 25 years, CSS could only select children, never parents. The revolutionary :has() pseudo-class changes web development forever. It allows an element to style itself based on its contents or children:

Code Example 4: The `:has()` Parent Selector

css
/* Style the card border red IF it contains an invalid input! */
.form-card:has(input:invalid) {
  border-color: #ef4444;
}

/* Style the body when a modal is open inside it (prevent background scrolling!) */
body:has(.modal-backdrop.is-active) {
  overflow: hidden;
}

/* Style a figure caption only if it contains an image */
figure:has(img) {
  background: #f1f5f9;
  border-radius: 8px;
}

6. Stylistic Polish with ::selection & ::marker

Customize small OS-level details for that high-end polished product aesthetic:

Code Example 5: Custom Selection & List Bullets

css
/* Change highlight color when user selects text with mouse */
::selection {
  background-color: #3b82f6;
  color: #ffffff;
}

/* Style list bullet dots directly */
ul.custom-list li::marker {
  color: #3b82f6;
  font-size: 1.2rem;
}

⚠ Common Beginner Mistakes
  • Forgetting content: "" on ::before/::after: Without this property, the browser will not allocate a box for the pseudo-element and it remains completely invisible.
  • Using :nth-child when meaning :nth-of-type: If you write p:nth-child(2), but the 2nd child in the container is an <h2>, the selector matches nothing! Use p:nth-of-type(2) if mixed elements share the parent.
  • Removing focus outlines globally: Writing * { outline: none; } breaks keyboard navigation for disabled users. Use :focus-visible instead.
  • Applying ::before to replaced elements: Elements like <img>, <input>, and <br> do not contain DOM children and cannot host ::before or ::after.
💡 Pro Tips from Senior Engineers
  • Zero-specificity resetting with :where(): When building component libraries or resets, wrapping selectors in :where() assigns them 0,0,0 specificity, allowing developers to override them with ease.
  • Combining :not() for clean lists: li:not(:last-child) { border-bottom: 1px solid #ccc; } avoids writing border resets on the final item.
  • Decorative icons via CSS: Use ::before { content: "\2713"; } to inject checkmarks into success messages without altering HTML markup.
⚡ Quick Recap
  • Pseudo-classes (:) target states; pseudo-elements (::) generate virtual DOM pieces.
  • Always provide :focus-visible styling for accessible keyboard navigation.
  • ::before and ::after strictly require content: "" to render.
  • :has() serves as the long-awaited parent and relational selector.
  • :is() takes the highest specificity of its arguments; :where() has zero specificity.
  • ::selection customizes text highlight colors.

8. Practice Coding Exercises

Exercise 1 (Easy): Accessible Keyboard Focus Ring Easy

Write the CSS rule that applies a 2px solid cyan outline with a 2px offset to links ONLY when navigating with the keyboard Tab key, without displaying it during mouse clicks.

Hint: Use the :focus-visible pseudo-class.
Solution:
a:focus-visible {
  outline: 2px solid cyan;
  outline-offset: 2px;
}
Exercise 2 (Medium): Zebra Striping a Table Medium

Write a CSS selector that targets every odd row inside a table body and changes its background to #f1f5f9, while leaving header rows untouched.

Hint: tbody tr:nth-child(odd).
Solution:
tbody tr:nth-child(odd) {
  background-color: #f1f5f9;
}
Exercise 3 (Hard): Select Parent Form Card Hard

Using the modern parent selector, write a single CSS rule that highlights the border of a .card in red whenever any checkbox inside that card is currently :checked.

Hint: .card:has(input[type="checkbox"]:checked).
Solution:
.card:has(input[type="checkbox"]:checked) {
  border-color: #ef4444;
}
