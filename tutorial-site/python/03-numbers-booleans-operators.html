🌟 Real-Life Analogy (10th-Grade Mental Model)

Think of division when sharing 7 slices of pizza between 2 people. True division (/) is using a pizza cutter: each person gets exactly 3.5 slices (a float). Floor division (//) is only giving out whole slices: each person gets 3 whole slices, and nobody gets fractions. Modulo (%) is checking how many leftover slices remain in the box: 7 % 2 = 1 slice leftover! The Walrus Operator (:=) is like measuring and cutting wood at the exact same moment: instead of measuring on line 1 and cutting on line 2, you measure and make the cut in one single motion! 🗣️ How to Speak in an Interview (Crisp Speaking Points)
  • True Division (/) vs Floor Division (//): In Python 3, / always returns a float (e.g. 4 / 2 returns 2.0). // performs floor division, rounding down to the nearest lower integer (e.g. 7 // 2 = 3, and -7 // 2 = -4!).
  • Boolean Short-Circuit Evaluation: In A and B, if A is False, Python never evaluates B. In A or B, if A is True, Python returns A immediately without evaluating B.
  • The Walrus Operator (:=): Introduced in Python 3.8 (PEP 572), assignment expressions allow assigning values to variables inside expressions (e.g. while (line := file.readline()):).
  • Identity (is) vs Equality (==): == checks equality of values; is checks if two operands refer to the exact same memory address.
  • Float Precision Trap: 0.1 + 0.2 == 0.3 is False due to IEEE 754 binary floating point representation! Use math.isclose(0.1 + 0.2, 0.3) or the decimal.Decimal class.

1. Arithmetic Operators & Integer Math

Python supports all standard arithmetic operations. Unlike legacy Python 2, Python 3 handles division with clean, predictable mathematical semantics:

• + (Add), - (Subtract), * (Multiply)
• / (True division — always produces float)
• // (Floor division — rounds down towards negative infinity)
• % (Modulo — remainder after division)
• ** (Exponentiation — e.g. 2 ** 8 = 256).

2. Logical Operators & Short-Circuit Evaluation

Python uses readable English words and, or, and not instead of symbols like &&, ||, and !.

Python logical operators return the actual operand object that determined the result, not just a raw boolean. For example: 'Apple' or 'Banana' returns 'Apple'!

3. The Python 3.8+ Walrus Operator (:=)

The walrus operator := (named because it looks like the eyes and tusks of a walrus) allows you to assign a variable while simultaneously checking its condition.

This eliminates redundant calculations in while loops, regex matching, and list comprehensions.

Practical Hands-On Code Demonstrations

Code Example 1: Division Semantics: True Division vs Floor Division vs Modulo

python
# 1. True division always yields float
print(f'8 / 2 = {8 / 2}')    # 4.0
print(f'7 / 2 = {7 / 2}')    # 3.5

# 2. Floor division rounds down
print(f'7 // 2 = {7 // 2}')   # 3
print(f'-7 // 2 = {-7 // 2}') # -4 (Notice it rounds towards negative infinity!)

# 3. Modulo remainder
print(f'7 % 2 = {7 % 2}')    # 1

# 4. Exponentiation
print(f'2 ** 10 = {2 ** 10}') # 1024
• Notice that -7 // 2 evaluates to -4 because floor division rounds towards negative infinity, not zero.

Code Example 2: Boolean Short-Circuiting in Action

python
def expensive_database_call():
    print('Executing heavy database query...')
    return True

# Short-circuit OR: First operand is True, second function NEVER runs!
flag = True
result = flag or expensive_database_call()
print('OR evaluated without calling expensive function!')

# Short-circuit AND: First operand is False, second function NEVER runs!
flag_false = False
result_and = flag_false and expensive_database_call()
• Short-circuiting saves massive CPU and network latency by avoiding unnecessary function calls.

Code Example 3: The Walrus Operator (:=) in Real-World Code

python
# Without Walrus operator (repetitive call to len):
sentence = 'Python full-stack engineering is powerful'
if len(sentence) > 20:
    print(f'Sentence is too long: {len(sentence)} chars')

# With Walrus operator (evaluates and assigns in one clean step!):
if (n := len(sentence)) > 20:
    print(f'Sentence length of {n} characters exceeds the 20-char threshold!')
• (n := len(sentence)) assigns the length to variable n and immediately evaluates n > 20.

Code Example 4: Floating Point Precision Trap and How to Fix It

python
import math
from decimal import Decimal

# The famous IEEE 754 float quirk
print(f'0.1 + 0.2 == 0.3: {0.1 + 0.2 == 0.3}')  # False!
print(f'Actual value: {0.1 + 0.2}')             # 0.30000000000000004

# Solution 1: math.isclose() for scientific calculations
print(f'math.isclose: {math.isclose(0.1 + 0.2, 0.3)}')  # True

# Solution 2: Decimal class for financial calculations
a = Decimal('0.1')
b = Decimal('0.2')
print(f'Decimal exact sum: {a + b == Decimal("0.3")}')  # True!
• Never use standard floats for billing systems or crypto wallets; always use decimal.Decimal.

Code Example 5: Bitwise Operators in Systems Programming

python
# Bitwise flags for permissions: READ=4 (100), WRITE=2 (010), EXEC=1 (001)
READ = 0b100
WRITE = 0b010
EXEC = 0b001

# Grant Read and Write permissions using bitwise OR (|)
user_perms = READ | WRITE
print(f'User Perms Binary: {bin(user_perms)}')  # 0b110

# Check if user has WRITE permission using bitwise AND (&)
has_write = bool(user_perms & WRITE)
print(f'Has write permission? {has_write}')  # True

# Bit shift: multiplying or dividing by powers of 2
print(f'5 shifted left by 1 (5 * 2): {5 << 1}')  # 10
• Bitwise operators manipulate raw binary bits directly in CPU registers, enabling lightning-fast permission checks.

Code Example 6: Useful Built-in Math Functions

python
import math

numbers = [12, -45, 78, 3, 99, -15]
print(f'Absolute of -45: {abs(-45)}')  # 45
print(f'Max: {max(numbers)}, Min: {min(numbers)}')  # 99, -45
print(f'Square root of 144: {math.isqrt(144)}')    # 12
print(f'Ceil 4.2: {math.ceil(4.2)}, Floor 4.9: {math.floor(4.9)}') # 5, 4
• math.isqrt() computes integer square roots without floating point conversions.

⚠️ Common Beginner & Production Mistakes
  • Expecting 0.1 + 0.2 == 0.3 to be True: Binary floats cannot represent 1/10 exactly. Use math.isclose() or Decimal.
  • Confusing / and //: In Python 3, 4 / 2 returns float 2.0, not integer 2. If you need an integer result, use 4 // 2.
  • Forgetting negative floor division behavior: -5 // 2 is -3, not -2, because it rounds down towards negative infinity!
💡 Senior Python Engineer Pro Tips
  • Chained Comparisons: Python allows natural mathematical chaining: if 10 <= age <= 20: instead of if age >= 10 and age <= 20:. It is faster and reads like pure math!
  • divmod() function: When you need both quotient and remainder, use quotient, remainder = divmod(17, 5) instead of calculating // and % separately.
⚑ Quick Recap & Key Takeaways
  • True division (/) always returns a float; floor division (//) rounds down to nearest lower integer.
  • Modulo (%) returns the division remainder.
  • Logical operators (and, or, not) short-circuit evaluation.
  • The Walrus operator (:=) enables assignment expressions inside conditions.
  • Use Decimal for currency calculations to prevent floating point drift.
