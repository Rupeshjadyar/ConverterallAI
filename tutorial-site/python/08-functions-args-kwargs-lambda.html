🗣️ How to Speak in an Interview (Crisp Speaking Points)
  • First-Class Functions: In Python, functions are first-class citizens. They can be assigned to variables, passed as arguments to other functions, returned from other functions, and stored in data structures.
  • What is *args and **kwargs?
    • *args collects arbitrary positional arguments into a tuple.
    • **kwargs collects arbitrary keyword arguments into a dictionary.
  • The Mutable Default Argument Trap (Top #1 Python Interview Question!):
    In Python, default parameter expressions are evaluated ONCE at function definition time, NOT at function call time! If you use a mutable default like def add(x, lst=[]), all invocations share the EXACT same list in memory! Fix: Always use def add(x, lst=None): if lst is None: lst = [].
  • What is a Closure? An inner function that retains access to variables from its enclosing lexical scope, even after the outer function has finished executing.
  • Keyword-Only Arguments (*): Placing a bare * in parameter lists forces all subsequent parameters to be passed strictly as keyword arguments (e.g. def connect(host, port, *, timeout=30):).

1. Anatomy of a Python Function

Functions are declared using the def keyword. Unlike languages that require return type declarations, Python functions return None by default if no explicit return statement is encountered.

Modern Python code uses type hints (PEP 484) to declare expected argument types and return types: def calculate_tax(income: float) -> float:.

2. Arbitrary Arguments: *args and **kwargs

When building generic utilities, decorators, or API wrappers, you often do not know in advance how many arguments a caller will supply.

Python allows unpacking variable-length arguments: *args packages extra positional values into a tuple, while **kwargs packages extra named values into a dictionary.

3. The Infamous Mutable Default Argument Trap

Every Python interview tests this bug. Consider: def append_item(val, items=[]): items.append(val); return items.

Because the function definition executes once when the module loads, the list [] is created once. Calling append_item(1) followed by append_item(2) returns [1, 2] because both calls share the same list!

Code Example 1: Defining Clean Functions with Type Hints & Docstrings

python
def calculate_discount(price: float, discount_percent: float = 10.0) -> float:
    """Calculate the final price after applying a percentage discount.
    
    Args:
        price: Original item cost.
        discount_percent: Percentage to deduct (default 10.0%).
    Returns:
        Final discounted price rounded to 2 decimal places.
    """
    discount_amount = price * (discount_percent / 100.0)
    return round(price - discount_amount, 2)

print(f'Standard 10% off $100: ${calculate_discount(100.0)}')
print(f'Special 25% off $200: ${calculate_discount(200.0, 25.0)}')
• Type hints and docstrings turn functions into clear, professional documentation.

Code Example 2: Arbitrary Arguments with *args and **kwargs

def build_user_profile(user_id, *roles, **metadata):
    print(f'User ID: {user_id}')
    print(f'Roles Tuple (*args): {roles}')
    print(f'Metadata Dict (**kwargs): {metadata}')

build_user_profile(

• *roles receives a tuple of strings; **metadata receives a dictionary of keyword parameters.

Code Example 3: The Mutable Default Argument Bug & The Correct Fix

python
# THE BUG:
def buggy_append(item, storage=[]):
    storage.append(item)
    return storage

print(buggy_append('A'))  # ['A']
print(buggy_append('B'))  # ['A', 'B']  <-- Shared state contamination!

# THE FIX (Sentinel None pattern):
def safe_append(item, storage=None):
    if storage is None:
        storage = []  # Fresh list allocated on each call!
    storage.append(item)
    return storage

print(safe_append('A'))   # ['A']
print(safe_append('B'))   # ['B']  <-- Clean and independent!
• Always use storage=None as the default parameter for mutable objects (lists, dicts, sets).

Code Example 4: Closures: Functions Retaining Enclosing State

python
def create_multiplier(factor: int):
    """Outer function that creates and returns an inner multiplier function."""
    def multiplier(number: int) -> int:
        # Inner function remembers 'factor' even after outer function exits!
        return number * factor
    return multiplier

double = create_multiplier(2)
triple = create_multiplier(3)

print(f'Double 10: {double(10)}')  # 20
print(f'Triple 10: {triple(10)}')  # 30
• Closures form the foundational mechanism behind Python Decorators.

Code Example 5: Lambda Anonymous Functions with map(), filter(), and sorted()

python
products = [
    ('Keyboard', 45.00),
    ('Mouse', 25.00),
    ('Monitor', 180.00),
    ('Cable', 12.00)
]

# 1. Sort by price ascending using lambda
sorted_by_price = sorted(products, key=lambda item: item[1])
print(f'Cheapest item: {sorted_by_price[0]}')

# 2. Filter high-value products
expensive = list(filter(lambda p: p[1] > 40.00, products))
print(f'Expensive products: {expensive}')

# 3. Map to uppercase names
names = list(map(lambda p: p[0].upper(), products))
print(f'Upper names: {names}')
• Lambdas are quick, 1-line anonymous functions with syntax: lambda args: expression.

Code Example 6: Keyword-Only Arguments using Bare Asterisk (*)

python
# Bare asterisk forces caller to explicitly name parameters after it
def connect_db(host, port, *, secure=True, timeout=30):
    return f'Connecting to {host}:{port} (SSL={secure}, Timeout={timeout}s)'

# Valid: keyword specified explicitly
print(connect_db('localhost', 5432, secure=False))

# Invalid: connect_db('localhost', 5432, False) -> Raises TypeError!
• Keyword-only arguments prevent confusing boolean flag calls like f(True, False, True) by forcing self-documenting code.

⚠️ Common Beginner & Production Mistakes
  • Using mutable defaults (lst=[]): Causes subtle cross-request state contamination in web applications.
  • Forgetting return in functions: Omitting return causes the function to implicitly return None.
  • Overusing complex Lambdas: If a lambda requires complex logic, loops, or multiple lines, write a regular named def function instead. PEP 8 prioritizes readability!
💡 Senior Python Engineer Pro Tips
  • Use functools.lru_cache for memoization: Add @functools.lru_cache(maxsize=128) over expensive recursive or computational functions to cache inputs and outputs in memory automatically!
  • Unpacking dictionaries into function calls: You can pass a dictionary to a function using func(**config_dict) to unpack named arguments dynamically.
⚑ Quick Recap & Key Takeaways
  • Functions are first-class citizens in Python.
  • *args packs positional arguments into a tuple; **kwargs packs keyword arguments into a dict.
  • Never use mutable default arguments (use None sentinel pattern instead).
  • Closures remember variables from outer enclosing scopes.
  • Lambda functions provide concise 1-line anonymous functions.

Exercise 3: Write a higher-order function time_it(func) that takes any function func as an argument, executes it, and prints the time taken in seconds using time.perf_counter().

💡 Hint: Create an inner wrapper(*args, **kwargs) that measures start and end time.

import time

def time_it(func):
    def wrapper(*args, **kwargs):
        start = time.perf_counter()
        result = func(*args, **kwargs)
        elapsed = time.perf_counter() - start
        print(f'{func.__name__} executed in {elapsed:.6f} seconds')
        return result
    return wrapper

@time_it
def compute_squares():
    return [x**2 for x in range(100000)]

compute_squares()
