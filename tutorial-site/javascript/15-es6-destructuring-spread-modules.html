1. Object Destructuring

Object destructuring extracts properties from an object and binds them to distinct variables matching the property keys:

Code Example 1: Basic & Advanced Object Destructuring

javascript
const userProfile = {
  id: 489,
  username: "alex_dev",
  email: "alex@example.com",
  role: "admin",
  location: {
    city: "San Francisco",
    country: "USA"
  }
};

// 1. Basic Destructuring:
const { username, email } = userProfile;
console.log(username); // "alex_dev"

// 2. Renaming during extraction & Providing Default Fallback:
const { role: userRole, avatarUrl = "default-avatar.png" } = userProfile;
console.log(userRole);   // "admin" (renamed from 'role')
console.log(avatarUrl);  // "default-avatar.png" (applied default because avatarUrl was undefined)

// 3. Nested Destructuring:
const { location: { city } } = userProfile;
console.log(city); // "San Francisco"

// 4. In Function Parameter Signatures (Senior Standard!):
function displayUserBadge({ username, role }) {
  console.log(`Badge: @${username} [${role.toUpperCase()}]`);
}
displayUserBadge(userProfile); // "Badge: @alex_dev [ADMIN]"

2. Array Destructuring

Array destructuring unpacks items based on their numerical index position:

Code Example 2: Array Destructuring & Value Swapping

javascript
const coordinates = [37.7749, -122.4194, 15]; // [lat, lng, altitude]

// 1. Extract by position:
const [latitude, longitude] = coordinates;
console.log(`Lat: ${latitude}, Lng: ${longitude}`);

// 2. Skipping items using empty commas:
const [lat, , altitude] = coordinates;
console.log(`Altitude: ${altitude}`); // 15

// 3. SWAPPING TWO VARIABLES WITHOUT A TEMP VARIABLE:
let primaryColor = "blue";
let secondaryColor = "orange";

// The modern 1-line swap idiom:
[primaryColor, secondaryColor] = [secondaryColor, primaryColor];
console.log(primaryColor);   // "orange"
console.log(secondaryColor); // "blue"

3. The Spread Operator (`...`): Expanding Data

When the three dots (...) appear on the right side of an assignment or in a function call, they act as the Spread Operator — expanding an iterable into its individual elements:

Code Example 3: Spreading Arrays and Objects

javascript
// 1. Array Cloning & Merging:
const frontEnd = ["HTML", "CSS", "JavaScript"];
const backEnd = ["Node.js", "PostgreSQL"];

const fullStack = [...frontEnd, ...backEnd, "DevOps"];
console.log(fullStack); // ["HTML", "CSS", "JavaScript", "Node.js", "PostgreSQL", "DevOps"]

// 2. Object Merging & Shallow Cloning:
const defaultSettings = {
  theme: "light",
  fontSize: 14,
  notifications: true
};

const userPreferences = {
  theme: "dark", // Overrides default!
  fontSize: 18
};

// Merges objects (properties on the right overwrite properties on the left):
const finalSettings = { ...defaultSettings, ...userPreferences };
console.log(finalSettings); 
// { theme: "dark", fontSize: 18, notifications: true }

4. The Rest Operator (`...`): Collecting Data

When the three dots appear on the left side of an assignment (in destructuring or function parameters), they act as the Rest Operator — gathering remaining elements into an array or object:

Code Example 4: Rest Gathering in Destructuring

javascript
// 1. Rest in Array Destructuring:
const [winner, runnerUp, ...participants] = ["Alice", "Bob", "Charlie", "David", "Emma"];
console.log(winner);        // "Alice"
console.log(participants);  // ["Charlie", "David", "Emma"]

// 2. Rest in Object Destructuring:
const serverResponse = {
  status: 200,
  message: "OK",
  data: [1, 2, 3],
  timestamp: 1761500000000
};

// Extract 'status' and gather all other metadata into 'metadata':
const { status, ...metadata } = serverResponse;
console.log(status);   // 200
console.log(metadata); // { message: "OK", data: [1,2,3], timestamp: 1761500000000 }

5. Crash Protection: Optional Chaining (`?.`)

Before ES2020, attempting to read a deeply nested property on an object where an intermediate key was null or undefined crashed the entire application with an uncaught TypeError: Cannot read properties of undefined.

Optional Chaining (?.) immediately short-circuits and returns undefined if any part of the path is nullish:

Code Example 5: Optional Chaining in Action

javascript
const userAccount = {
  id: 12,
  profile: null // Profile has not been filled out yet!
};

// OLD DANGEROUS CODE:
// const avatar = userAccount.profile.avatar; // CRASH! TypeError!

// MODERN CRASH-PROOF CODE:
const avatar = userAccount?.profile?.avatar;
console.log(avatar); // undefined (No crash! Execution continues safely!)

// Combine with Nullish Coalescing (??) for the ultimate safe fallback:
const avatarFinal = userAccount?.profile?.avatar ?? "default-avatar.png";
console.log(avatarFinal); // "default-avatar.png"

6. ES6 Modules: `export` & `import`

Modules allow you to break massive codebases into separate, organized files:

Code Example 6: Named vs Default Exports

javascript
// --- In file: mathUtils.js ---
// 1. Named Exports (Can export multiple items):
export const PI = 3.14159;
export function add(a, b) { return a + b; }

// 2. Default Export (Only ONE per file):
export default function multiply(a, b) { return a * b; }


// --- In file: app.js ---
// Importing named exports (in curly braces) and default export:
import multiply, { PI, add } from "./mathUtils.js";

console.log(add(5, 10));     // 15
console.log(multiply(4, 5)); // 20

⚠ Common Beginner Mistakes
  • Placing Rest (...) before other parameters: The Rest parameter MUST be the final element in an array pattern or function parameter list. Writing function test(...rest, lastItem) throws a fatal SyntaxError!
  • Assuming spread creates deep clones: Spread syntax ({ ...obj }) performs a shallow copy. If an object contains nested objects or arrays, the nested objects are still copied by reference!
  • Missing type="module" in HTML: If you use import and export in browser scripts, the HTML script tag MUST declare <script type="module" src="app.js">.
💡 Pro Tips from Senior Engineers
  • Destructure directly in React/UI parameters: Destructuring props right in the function head (function Card({ title, price, isFeatured })) makes components instantly self-documenting.
  • Optional chaining with function calls: You can use optional chaining to safely execute callbacks that might be undefined: onSuccess?.(data)!
  • Clone and override in one move: When updating state immutably: const updatedUser = { ...user, age: user.age + 1 };.
⚡ Quick Recap
  • Object destructuring extracts by key name; array destructuring extracts by index position.
  • Swap variables in 1 line: [a, b] = [b, a].
  • Spread (...) expands iterables for shallow cloning and merging.
  • Rest (...) collects leftover items into an array or object.
  • Optional chaining (?.) halts errors on undefined intermediate properties.
  • ES Modules use export and import for clean separation of concerns.

8. Practice Coding Exercises

Exercise 1 (Easy): One-Line Swap Easy

Given let x = 1; let y = 2;, write the single-line array destructuring statement that swaps their values so x === 2 and y === 1.

Hint: [x, y] = [y, x];
Solution:
[x, y] = [y, x];
Exercise 2 (Medium): Merge Objects with Override Medium

Given const base = { theme: "light", font: "sans", size: 14 };, use object spread to create a new object custom that has all properties of base, but overrides theme with "dark".

Hint: const custom = { ...base, theme: "dark" };
Solution:
const custom = { ...base, theme: "dark" };
Exercise 3 (Hard): Deep Safe Extraction Hard

You receive an unknown API response object data. Write an expression using Optional Chaining and Nullish Coalescing to extract data.results[0].author.name, falling back to "Anonymous" if any part of the path is missing.

Hint: data?.results?.[0]?.author?.name ?? "Anonymous"
Solution:
const authorName = data?.results?.[0]?.author?.name ?? "Anonymous";
