1. String Manipulation Mastery

Strings are immutable in JavaScript — methods never modify the original string, they always return a fresh new string:

Code Example 1: Core String Methods

javascript
const rawEmail = "   User.Account@Domain.COM  \n";

// 1. Cleaning input: trim and lowercase
const cleanEmail = rawEmail.trim().toLowerCase();
console.log(cleanEmail); // "user.account@domain.com"

// 2. Searching within strings
const statement = "JavaScript is the engine of the web";
console.log(statement.includes("engine"));   // true
console.log(statement.startsWith("Java"));   // true
console.log(statement.endsWith("web"));      // true

// 3. Slicing sections (start, endNonInclusive)
const codeSnippet = statement.slice(0, 10);  // "JavaScript"

// 4. Replacing content
const promptText = "Cats are cool. Cats are fast.";
console.log(promptText.replace("Cats", "Dogs"));    // "Dogs are cool. Cats are fast." (First match only)
console.log(promptText.replaceAll("Cats", "Dogs")); // "Dogs are cool. Dogs are fast." (All matches!)

// 5. Splitting strings into Arrays:
const csv = "Apple,Banana,Orange";
const fruitList = csv.split(","); // ["Apple", "Banana", "Orange"]

2. Numbers & Precision Rounding

JavaScript represents all numbers using IEEE 754 64-bit floating-point format. This introduces famous precision quirks like 0.1 + 0.2 === 0.30000000000000004:

Code Example 2: Number Formatting & Validation

javascript
const rawPrice = 19.9567;

// toFixed(digits): Formats to exact decimal places (RETURNS A STRING!)
const formattedPrice = rawPrice.toFixed(2); // "19.96" (Rounded properly)

// Safe Number Checking:
console.log(Number.isInteger(42));    // true
console.log(Number.isInteger(42.5));  // false

// Checking for NaN safely:
console.log(Number.isNaN(NaN));       // true
console.log(Number.isNaN("hello"));   // false (Strictly tests without coercion!)

3. The `Math` Object

The Math object contains mathematical constants and static utility functions:

Code Example 3: Rounding and Random Ranges

javascript
// 1. The 4 Rounding Functions:
console.log(Math.round(4.5)); // 5 (Standard round to nearest)
console.log(Math.floor(4.9)); // 4 (Always rounds DOWN)
console.log(Math.ceil(4.1));  // 5 (Always rounds UP)
console.log(Math.trunc(4.9)); // 4 (Simply cuts off decimals)

// 2. Extrema:
console.log(Math.min(10, 5, 40, -2)); // -2
console.log(Math.max(10, 5, 40, -2)); // 40

// 3. THE RANDOM INTEGER FORMULA:
// Math.random() returns a floating number from 0 (inclusive) up to 1 (exclusive)
function getRandomInt(min, max) {
  min = Math.ceil(min);
  max = Math.floor(max);
  return Math.floor(Math.random() * (max - min + 1)) + min;
}

// Generate a random dice roll (1 to 6):
const diceRoll = getRandomInt(1, 6);
console.log(`Dice rolled: ${diceRoll}`);

4. The `Date` Object & Timestamps

JavaScript dates represent milliseconds elapsed since the Unix Epoch (January 1, 1970 UTC):

The Infamous Month Trap: In JavaScript, months are 0-indexed! 0 is January, 5 is June, and 11 is December. However, days of the month (getDate()) start at 1!

Code Example 4: Creating & Reading Dates

javascript
// 1. Current Date & Time:
const now = new Date();

// 2. Specific Date: new Date(year, monthIndex, day, hour, min, sec)
const launchDate = new Date(2026, 9, 26); // October 26, 2026! (Month 9 is October)

// 3. Date Getters:
console.log(now.getFullYear()); // 2026
console.log(now.getMonth());    // 0-11
console.log(now.getDate());     // 1-31 (Day of month)
console.log(now.getDay());      // 0-6 (0 is Sunday, 6 is Saturday)

// 4. Current Timestamp in Milliseconds (Great for performance timing):
const timestamp = Date.now(); // e.g. 1761500000000

5. Professional Internationalization (Intl)

Never build custom string-formatting hacks for currencies or dates. Modern browsers include the built-in Intl API for localized formatting without external dependencies:

Code Example 5: Clean Localized Formatting

javascript
// 1. Currency Formatting (US Dollars vs Euros vs Indian Rupees):
const usCurrency = new Intl.NumberFormat("en-US", { style: "currency", currency: "USD" });
console.log(usCurrency.format(12499.50)); // "$12,499.50"

const inrCurrency = new Intl.NumberFormat("en-IN", { style: "currency", currency: "INR" });
console.log(inrCurrency.format(12499.50)); // "₹12,499.50"

// 2. Human-Readable Date Formatting:
const dateRenderer = new Intl.DateTimeFormat("en-US", {
  dateStyle: "full",
  timeStyle: "short"
});
console.log(dateRenderer.format(new Date())); 
// "Monday, October 26, 2026 at 11:30 PM"

⚠ Common Beginner Mistakes
  • Forgetting that toFixed() returns a String: Writing val.toFixed(2) + 10 results in string concatenation (e.g. "19.9910"). Wrap with Number(val.toFixed(2)) if further math is required.
  • Setting month to 12 in Date: In new Date(2026, 12, 1), month 12 wraps around to January of 2027! Remember December is index 11.
  • Expecting Math.random() to generate integers: Math.random() returns a decimal between 0 and 1. You must multiply and use Math.floor().
  • Thinking strings can be modified in place: Writing str[0] = "Z" does not modify the string; strings are strictly immutable in JavaScript.
💡 Pro Tips from Senior Engineers
  • Reverse a string in one line: str.split("").reverse().join("") is the canonical reversal idiom.
  • Pad numbers with leading zeros: Use String(day).padStart(2, "0") to ensure dates like "5" format cleanly as "05"!
  • Use crypto.randomUUID(): Modern browsers have built-in UUID generation without needing any third-party npm package: const id = crypto.randomUUID();!
⚡ Quick Recap
  • Strings are immutable; methods return fresh transformed strings.
  • toFixed(2) formats decimals and returns a string.
  • Math.floor() rounds down; Math.ceil() rounds up.
  • Random integer formula: Math.floor(Math.random() * (max - min + 1)) + min.
  • Date months are 0-indexed (0 = Jan, 11 = Dec); days are 1-indexed.
  • Use the native Intl API for localized currencies and dates.

Exercise 3 (Hard): Days Between Two Dates Hard

Write a function getDaysBetween(date1, date2) that calculates the absolute number of full days between two JavaScript Date objects.

Hint: Subtract timestamps to get milliseconds, divide by (1000 * 60 * 60 * 24), and Math.abs().
Solution:
function getDaysBetween(d1, d2) {
  const diffMs = Math.abs(d2.getTime() - d1.getTime());
  const msInDay = 1000 * 60 * 60 * 24;
  return Math.floor(diffMs / msInDay);
}
