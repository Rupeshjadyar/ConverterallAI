1. What is the DOM?

When a web browser loads an HTML file, it parses the raw text and converts it into a hierarchical tree of JavaScript objects called the Document Object Model (DOM).

The root entry point to this tree is the global document object. Through document, JavaScript has full programmatic access to read, change, add, or delete any HTML tag, attribute, or CSS style on the page in real time!

2. Selecting Elements: Modern vs Legacy

Modern JavaScript provides two versatile CSS-selector based query methods that replace older legacy methods:

Code Example 1: Selecting DOM Elements

javascript
// 1. querySelector: Returns the FIRST matching element (or null)
// Accepts ANY valid CSS selector!
const mainHeader = document.querySelector("#app-header");
const primaryBtn = document.querySelector(".btn-primary");
const activeNavLink = document.querySelector("nav > ul li.active a");

// 2. querySelectorAll: Returns a static NodeList of ALL matching elements
const allCards = document.querySelectorAll(".card");
console.log(`Found ${allCards.length} cards.`);

// You can loop over a NodeList directly with for...of or forEach:
allCards.forEach((card, index) => {
  console.log(`Card #${index + 1}:`, card);
});

// 3. Fast ID Selector (Fastest raw performance for ID lookup):
const submitButton = document.getElementById("submit-btn");

3. Updating Content: `textContent` vs `innerHTML`

Updating text on screen is the most common DOM operation. Understanding the security difference between these properties is vital:

Code Example 2: Safe Text vs HTML Injection

javascript
const titleEl = document.querySelector("#title");
const bioEl = document.querySelector("#bio");

// 1. textContent (SENIOR STANDARD):
// Safe, fast, renders raw text, automatically escapes HTML tags!
titleEl.textContent = "Welcome to our Platform!";

// 2. innerHTML:
// Parses string as live HTML markup.
bioEl.innerHTML = "Senior Engineer at Acme Corp";

⚠ Common Beginner Mistakes
  • Forgetting that querySelectorAll returns a NodeList: You cannot write document.querySelectorAll(".card").style.color = "red"! You must loop over the items with forEach() or iterate with for...of.
  • Missing the dot (.) in class queries: Writing document.querySelector("btn") looks for a custom HTML tag <btn>! To target a class, write document.querySelector(".btn").
  • Using innerHTML for plain text: innerHTML forces the browser to invoke its internal HTML parser, which is slower and creates Cross-Site Scripting (XSS) risks. Use textContent for pure text.
  • Directly overriding className: Writing el.className = "active" deletes all other existing classes on that element. Always use el.classList.add("active").
💡 Pro Tips from Senior Engineers
  • Scope selections to container elements: Instead of querying from document every time, query from a parent container: const cardTitle = card.querySelector(".title"); for cleaner component encapsulation.
  • Check if element exists before modifying: Prevent null pointer crashes: const btn = document.querySelector(".btn"); if (btn) { btn.classList.add("ready"); } (or optional chaining btn?.classList.add("ready")).
  • Batch class updates: classList.add() and classList.remove() accept multiple class names: el.classList.add("bold", "text-blue", "shadow");!
⚡ Quick Recap
  • The DOM is a tree of JavaScript objects representing the HTML page.
  • querySelector selects first match; querySelectorAll returns a NodeList of all matches.
  • Use textContent for safe, fast text updates. Avoid innerHTML with user input.
  • Use classList.add(), remove(), toggle(), and contains() for clean CSS state management.
  • Read data-* HTML attributes via the element.dataset camelCase API.

8. Practice Coding Exercises

Exercise 1 (Easy): Select by Class and Toggle State Easy

Write the JavaScript lines to select the first element with class .sidebar and toggle the class is-collapsed on it.

Hint: querySelector and classList.toggle.
Solution:
const sidebar = document.querySelector(".sidebar");
sidebar.classList.toggle("is-collapsed");
Exercise 2 (Medium): Change All Subtitles Medium

Using querySelectorAll, select all elements with class .subtitle on the page and change their text to "Updated Subtitle" using a loop.

Hint: Loop over the NodeList with forEach or for...of and set textContent.
Solution:
const subtitles = document.querySelectorAll(".subtitle");
subtitles.forEach(el => {
  el.textContent = "Updated Subtitle";
});
Exercise 3 (Hard): Read Custom Data Attribute Hard

An element is defined as: <div id="product" data-product-sku="SKU-9902" data-stock-count="45"></div>. Write the code to read both values using the dataset property.

Hint: dataset converts kebab-case to camelCase.
Solution:
const productEl = document.getElementById("product");
const sku = productEl.dataset.productSku;     // "SKU-9902"
const stock = Number(productEl.dataset.stockCount); // 45
