1. Object Literals: Properties & Accessors

An Object is an unordered collection of related key-value pairs. Keys are strings (or Symbols), and values can be any valid JavaScript type:

Code Example 1: Dot vs Bracket Notation

javascript
const user = {
  id: 101,
  name: "Sophia Martinez",
  email: "sophia@example.com",
  "favorite framework": "Vanilla JS", // Property with spaces must be quoted!
  age: 27
};

// 1. Dot Notation (Clean & Standard for fixed keys):
console.log(user.name);  // "Sophia Martinez"
user.age = 28;           // Updating a property

// 2. Bracket Notation (Mandatory for special characters & dynamic variables):
console.log(user["favorite framework"]); // "Vanilla JS"

const fieldToInspect = "email";
console.log(user[fieldToInspect]); // "sophia@example.com" (Evaluates variable!)

// 3. Adding & Deleting:
user.isAdmin = true; // Added
delete user.age;     // Removed

2. Object Methods and the 'this' Keyword

A function attached to an object is called a Method. Inside a method, the keyword this refers to the object that invoked the method (the object to the left of the dot):

Code Example 2: Method Declaration with `this`

javascript
const bankAccount = {
  owner: "Marcus Vance",
  balance: 5000,

  // Method shorthand syntax:
  deposit(amount) {
    this.balance += amount; // 'this' points directly to bankAccount
    return `Deposited $${amount}. New balance: $${this.balance}`;
  },

  printStatement() {
    console.log(`Account Owner: ${this.owner} | Funds: $${this.balance}`);
  }
};

console.log(bankAccount.deposit(500)); // "Deposited $500. New balance: $5500"
bankAccount.printStatement();          // "Account Owner: Marcus Vance | Funds: $5500"

3. The 4 Binding Rules of 'this'

How this is determined is one of the most notoriously misunderstood concepts in web development. Memorize these four clear rules:

Code Example 3: The Four Binding Rules Demonstrated

javascript
// RULE 1: Default Binding (Standalone function call)
function showThis() {
  console.log(this); // In non-strict mode: window (global). In "use strict": undefined!
}
showThis();

// RULE 2: Implicit Binding (Object method call)
const hero = {
  alias: "Spider-Man",
  greet() {
    console.log(`I am ${this.alias}`);
  }
};
hero.greet(); // 'this' is hero (Spider-Man)

// RULE 3: Explicit Binding (call, apply, bind)
function attack(damage, type) {
  console.log(`${this.alias} strikes for ${damage} ${type} damage!`);
}
// Force 'this' to point to hero:
attack.call(hero, 50, "web"); // Spider-Man strikes for 50 web damage!

// RULE 4: Lexical Binding (Arrow Functions)
// Arrow functions DO NOT have their own 'this'!
// They inherit 'this' from wherever they were written!

4. The Fatal Arrow Function Method Trap

Because arrow functions inherit this lexically from their enclosing scope, never use arrow functions as object methods:

Code Example 4: Arrow Function Method Bug

javascript
const person = {
  name: "Emily",
  // BAD: Arrow function method!
  badGreet: () => {
    console.log(`Hello, my name is ${this.name}`);
  },
  // GOOD: Standard method syntax!
  goodGreet() {
    console.log(`Hello, my name is ${this.name}`);
  }
};

person.badGreet();  // "Hello, my name is undefined" ! ('this' is window, NOT person!)
person.goodGreet(); // "Hello, my name is Emily" (Correct!)

5. Static Object Utilities: Keys, Values & Entries

The built-in global Object constructor provides essential static helper methods:

Code Example 5: Object Reflection Methods

javascript
const config = {
  theme: "dark",
  fontSize: 16,
  autoSave: true
};

// 1. Object.keys(): Returns array of property names
console.log(Object.keys(config));   // ["theme", "fontSize", "autoSave"]

// 2. Object.values(): Returns array of property values
console.log(Object.values(config)); // ["dark", 16, true]

// 3. Object.entries(): Returns array of [key, value] pairs (great for loops!)
for (const [key, value] of Object.entries(config)) {
  console.log(`Setting ${key} → ${value}`);
}

// 4. Object.freeze(): Prevents adding, removing, or modifying properties!
const immutableConfig = Object.freeze({ apiVersion: "v2" });
// immutableConfig.apiVersion = "v3"; // Fails silently (or throws in strict mode!)

⚠ Common Beginner Mistakes
  • Losing this when passing a method as a callback: Passing setTimeout(user.greet, 1000) tears the function away from user, causing this to become window! Fix: setTimeout(() => user.greet(), 1000) or user.greet.bind(user).
  • Using dot notation with dynamic variables: Writing user.myVariable looks for a literal key named "myVariable"! When using a variable as a key, you MUST use bracket notation: user[myVariable].
  • Assuming Object.freeze() is deep: Object.freeze() only freezes shallow 1st-level properties. Nested objects inside it remain mutable unless manually frozen recursively.
💡 Pro Tips from Senior Engineers
  • Property Shorthand: If your variable name matches your object key, write { name, age } instead of { name: name, age: age }.
  • Computed Property Names: You can create dynamic keys inside the object literal declaration itself using brackets: const obj = { [`key_${id}`]: "Dynamic Value" };.
  • Safely check property existence: Use "propertyName" in object or modern Object.hasOwn(obj, "propertyName") instead of relying on truthiness checks.
⚡ Quick Recap
  • Objects store data in key-value pairs; use dot notation for fixed keys and brackets for dynamic keys.
  • Methods are functions on objects; this refers to the calling object.
  • Never use arrow functions for object methods; they do not bind this to the object.
  • Explicitly bind this using .call(), .apply(), or .bind().
  • Use Object.keys(), Object.values(), and Object.entries() for object iteration.
  • Object.freeze() protects top-level properties from mutation.

7. Practice Coding Exercises

Exercise 1 (Easy): Dynamic Property Lookup Easy

Given const user = { name: "Alex", city: "Tokyo" }; and a variable const key = "city";, write the expression that reads the city name using the variable key.

Hint: Use bracket notation.
Solution:
user[key] (Evaluates to "Tokyo").
Exercise 2 (Medium): Fix the Broken 'this' Method Medium

Why does const car = { brand: "Tesla", getBrand: () => this.brand }; car.getBrand(); return undefined, and how do you fix it?

Hint: Replace arrow function with standard method shorthand.
Solution:
Arrow functions lack their own this and inherit it from the outer global scope where brand is undefined. Fix it using standard method shorthand: 
const car = {
  brand: "Tesla",
  getBrand() {
    return this.brand;
  }
};
Exercise 3 (Hard): Explicitly Bind a Detached Function Hard

Given a standalone function function introduce() { return "Hi, I am " + this.name; } and an object const person = { name: "Liam" };, write the code using .bind() to create a permanent new function boundIntroduce bound to person.

Hint: introduce.bind(person).
Solution:
const boundIntroduce = introduce.bind(person);
