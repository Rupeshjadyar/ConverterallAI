Tier 1: Syntax & Control Flow (Lessons 01 – 05) — Console, variables (let/const), primitive data types, arithmetic/comparison operators, conditional branching, and loops.

Tier 5: RegEx, Debugging & Best Practices (Lessons 21 – 22) — Regular expressions for pattern verification, Chrome DevTools breakpoints, avoiding memory leaks, and professional clean code principles.
