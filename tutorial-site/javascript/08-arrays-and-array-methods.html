1. Array Basics & 0-Indexing

An Array is an ordered list of values. Items inside an array can be any mixed data types, though professional code keeps array elements consistent:

Code Example 1: Creating & Accessing Arrays

javascript
const fruits = ["Apple", "Banana", "Cherry"];

console.log(fruits[0]); // "Apple" (First item)
console.log(fruits[1]); // "Banana"
console.log(fruits.length); // 3

// Accessing the last item:
console.log(fruits[fruits.length - 1]); // "Cherry"
// Or modern at() method (supports negative indices!):
console.log(fruits.at(-1)); // "Cherry"

2. Mutating Methods: Altering the Original Array

These methods modify the array directly in memory:

Code Example 2: Push, Pop, Shift, Unshift & Splice

javascript
const tasks = ["Design UI", "Write Code"];

// 1. push: Adds to END (returns new array length)
tasks.push("Test App"); // ["Design UI", "Write Code", "Test App"]

// 2. pop: Removes from END (returns the removed element)
const removedLast = tasks.pop(); // "Test App"

// 3. unshift: Adds to START
tasks.unshift("Brainstorm"); // ["Brainstorm", "Design UI", "Write Code"]

// 4. shift: Removes from START
const removedFirst = tasks.shift(); // "Brainstorm"

// 5. splice(startIndex, deleteCount, ...itemsToAdd): Swiss Army Knife
// Removes 1 item at index 1 and inserts "Review PR" in its place:
tasks.splice(1, 1, "Review PR");
console.log(tasks); // ["Design UI", "Review PR"]

3. The Shocking String Sorting Trap

By default, array.sort() converts elements to UTF-16 strings and sorts them alphabetically. This produces horrifying numerical bugs:

Code Example 3: Sorting Numbers Correctly

javascript
const scores = [10, 5, 25, 2, 100];

// THE BUG:
scores.sort();
console.log(scores); // [10, 100, 2, 25, 5] ! (Alphabetical string sorting!)

// THE SENIOR FIX: Always provide a Comparator Function (a, b)
// Ascending (lowest to highest):
scores.sort((a, b) => a - b);
console.log(scores); // [2, 5, 10, 25, 100]

// Descending (highest to lowest):
scores.sort((a, b) => b - a);
console.log(scores); // [100, 25, 10, 5, 2]

4. Non-Mutating Methods: Slice & Join

These methods return a new value without disturbing the source array:

Code Example 4: Slice, Join & Includes

javascript
const letters = ["A", "B", "C", "D", "E"];

// 1. slice(start, endNonInclusive): Copies a slice
const middle = letters.slice(1, 4); // ["B", "C", "D"]
console.log(letters); // Source remains completely untouched!

// 2. join(separator): Glues array items into a single string
const csv = letters.join(", "); // "A, B, C, D, E"

// 3. includes(val): Tests if item exists (returns true/false)
console.log(letters.includes("C")); // true
console.log(letters.includes("Z")); // false

5. The Big 4 Functional Higher-Order Methods

Higher-Order Methods take a callback function and apply it across every element. They represent modern idiomatic JavaScript:

Code Example 5: Map, Filter, Reduce & Find

javascript
const products = [
  { id: 1, name: "Keyboard", price: 80, inStock: true },
  { id: 2, name: "Mouse", price: 40, inStock: false },
  { id: 3, name: "Monitor", price: 250, inStock: true }
];

// 1. MAP: Transforms every item into a new shape (Returns brand new array)
const productNames = products.map(p => p.name);
console.log(productNames); // ["Keyboard", "Mouse", "Monitor"]

// 2. FILTER: Keeps only items that pass the truth test
const availableProducts = products.filter(p => p.inStock);
console.log(availableProducts); // [Keyboard, Monitor]

// 3. FIND: Returns the FIRST matching item (or undefined)
const monitor = products.find(p => p.id === 3);
console.log(monitor.name); // "Monitor"

// 4. REDUCE: Accumulates array into a single final value (acc, current)
const totalInventoryValue = products.reduce((accumulator, product) => {
  return accumulator + product.price;
}, 0); // 0 is the starting initial value!
console.log(`Total Value: $${totalInventoryValue}`); // $370

6. Method Chaining: The Declarative Data Pipeline

Because filter and map return brand-new arrays, you can chain them into readable data transformation pipelines:

Code Example 6: Real-World E-Commerce Pipeline

javascript
const transactions = [
  { type: "credit", amount: 150 },
  { type: "debit", amount: 45 },
  { type: "credit", amount: 200 },
  { type: "debit", amount: 10 }
];

// Pipeline: Filter credits -> Extract amounts -> Sum with reduce
const totalCreditRevenue = transactions
  .filter(t => t.type === "credit")       // [{ amount: 150 }, { amount: 200 }]
  .map(t => t.amount)                     // [150, 200]
  .reduce((sum, amount) => sum + amount, 0); // 350

console.log(`Total Credits: $${totalCreditRevenue}`); // $350

⚠ Common Beginner Mistakes
  • Sorting numbers without a comparator function: [9, 80].sort() produces [80, 9] because "80" comes before "9" in string alphabetical order! Always write (a, b) => a - b.
  • Confusing slice() and splice(): slice() is non-mutating and copies a portion. splice() mutates the original array by deleting or inserting elements.
  • Using map() when you don't return anything: If you just want to run an action without creating a new array, use forEach() or a for...of loop. Using map() creates an unnecessary array of undefineds in memory.
  • Forgetting the initial value in reduce(): If you omit the initial value (e.g. 0 or []), reduce() defaults to using the first array element, which causes runtime errors on empty arrays!
💡 Pro Tips from Senior Engineers
  • Remove duplicates with Set: const uniqueItems = [...new Set(myArray)]; is the fastest, cleanest one-liner to deduplicate an array!
  • Shallow array cloning with spread: const clone = [...originalArray]; creates a new shallow copy, preventing accidental mutations to the original source.
  • Use find() over filter()[0]: filter() examines the entire array even after finding a match. find() stops scanning immediately upon the first match, saving CPU cycles!
⚡ Quick Recap
  • Arrays are 0-indexed; access the last element with arr.at(-1).
  • Mutating methods: push, pop, shift, unshift, splice, sort.
  • Always pass (a, b) => a - b to sort() for numbers.
  • map() transforms elements; filter() subsets elements; reduce() aggregates values.
  • find() stops scanning on the first matching element.
  • Chain methods together for clean, declarative data processing pipelines.

8. Practice Coding Exercises

Exercise 1 (Easy): Double Every Number Easy

Using map(), write a one-line expression to transform const nums = [1, 2, 3, 4]; into an array with every number doubled ([2, 4, 6, 8]).

Hint: nums.map(n => n * 2);
Solution:
const doubled = nums.map(n => n * 2);
Exercise 2 (Medium): Filter Passing Grades Medium

Given const grades = [45, 80, 92, 58, 74, 30];, write an expression using filter() that extracts all passing grades (score 60 or higher) and sorts them ascending.

Hint: grades.filter(...).sort((a,b) => a - b);
Solution:
const passing = grades
  .filter(g => g >= 60)
  .sort((a, b) => a - b);
// [74, 80, 92]
Exercise 3 (Hard): Word Frequency Counter with Reduce Hard

Given const fruits = ["apple", "banana", "apple", "orange", "banana", "apple"];, use reduce() to produce an object tallying counts: { apple: 3, banana: 2, orange: 1 }.

Hint: accumulator[fruit] = (accumulator[fruit] || 0) + 1; return accumulator; with initial value {}.
Solution:
const counts = fruits.reduce((acc, fruit) => {
  acc[fruit] = (acc[fruit] || 0) + 1;
  return acc;
}, {});
