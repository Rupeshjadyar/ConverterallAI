Listen and react to human actions. Master the Event Loop, Capturing, Bubbling, and enterprise Event Delegation. Events aur Event Delegation: addEventListener, Event Bubbling (Capturing vs Bubbling), target vs currentTarget seekhein.

🌟 Real-Life Analogy: The Stone Dropped in an Ocean Pond

Picture dropping a smooth pebble into a clear forest pond:
• 1. The Capturing Phase (The Stone Sinking): The pebble travels down from the sky (window), passes the water surface (document), dives past weeds (body), until it touches the target sand pebble on the pond floor.
• 2. The Target Phase: The stone strikes the target leaf on the floor.
• 3. The Bubbling Phase (Air Bubbles Rising!): Tiny air bubbles released at the target float straight back up to the surface, triggering every lily pad above it along the way! In JavaScript, almost every user click bubbles upward like those air bubbles! 1. The `addEventListener` Foundation

Never attach events using legacy HTML inline attributes like onclick="...". Modern applications use addEventListener:

element.addEventListener(eventType, callbackFunction, options);

Code Example 1: Listening for Click & Keyboard Events

javascript
const actionBtn = document.querySelector("#launch-btn");

// 1. Listening to click events
actionBtn.addEventListener("click", (event) => {
  console.log("Button clicked!", event);
});

// 2. Listening to Keyboard Shortcuts across the entire window
window.addEventListener("keydown", (event) => {
  // Check if user pressed Escape key to close modals:
  if (event.key === "Escape") {
    console.log("Escape key detected! Closing active dialogs.");
  }

  // Check for modifier keys (Ctrl + Enter)
  if (event.ctrlKey && event.key === "Enter") {
    console.log("Ctrl+Enter detected! Submitting code.");
  }
});

2. Removing Event Listeners (The Anonymous Trap)

To prevent memory leaks when removing components, use removeEventListener.

The Fatal Anonymous Function Trap: You CANNOT remove a listener registered with an anonymous arrow function! removeEventListener requires the exact same function reference pointer in memory:

Code Example 2: Correct Listener Removal

javascript
// BAD (Fails silently; cannot remove an anonymous function!):
// btn.addEventListener("click", () => console.log("Hi"));
// btn.removeEventListener("click", () => console.log("Hi")); // Does nothing!

// GOOD (Named function reference):
function handleWindowResize(e) {
  console.log(`Window size: ${window.innerWidth}x${window.innerHeight}`);
}

window.addEventListener("resize", handleWindowResize);

// Now successfully removed:
window.removeEventListener("resize", handleWindowResize);

3. The Event Object: Target vs CurrentTarget

When an event handler fires, the browser automatically passes an Event object as the first parameter. Distinguishing between target and currentTarget is essential:

Property What It Points To Real-World Analogy
event.target The EXACT element that was clicked (e.g. icon inside a button) The child who knocked over the vase
event.currentTarget The element that OWNS the event listener currently handling it The parent who answered the door

4. PreventDefault vs StopPropagation

Two powerful control methods on the Event object:

Code Example 3: Halting Default Behavior & Bubbling

javascript
// 1. event.preventDefault(): Cancels default browser action
// (Stops link from navigating, stops form from reloading page)
document.querySelector("a.custom-link").addEventListener("click", (e) => {
  e.preventDefault();
  console.log("Link click intercepted! Navigating via SPA router instead.");
});

// 2. event.stopPropagation(): Stops event from bubbling up to parents!
document.querySelector(".inner-modal").addEventListener("click", (e) => {
  e.stopPropagation(); // Prevents click on modal from closing the backdrop!
});

5. The Senior Masterpiece: Event Delegation

Imagine you have a dynamic list of 5,000 chat messages or product cards.
• Junior Approach: Attaching 5,000 separate event listeners to every single card (wastes 50MB of RAM memory, and new messages added later don't have listeners!).
• Senior Approach (Event Delegation): Attach ONE SINGLE listener to the parent <ul> container! When a user clicks any item inside, the click bubbles up to the parent, where we catch it using event.target.closest():

Code Example 4: The Event Delegation Architecture

html
<ul id="todo-list">
  <li data-id="1"><span>Walk Dog</span> <button class="btn-delete">×</button></li>
  <li data-id="2"><span>Read Code</span> <button class="btn-delete">×</button></li>
</ul>
javascript
const todoList = document.querySelector("#todo-list");

// Single event listener on the PARENT container:
todoList.addEventListener("click", (event) => {
  // 1. Did the user click a delete button?
  const deleteBtn = event.target.closest(".btn-delete");
  if (deleteBtn) {
    const li = deleteBtn.closest("li");
    console.log(`Deleting todo ID: ${li.dataset.id}`);
    li.remove();
    return;
  }

  // 2. Did the user click the li item to toggle completed?
  const li = event.target.closest("li");
  if (li) {
    li.classList.toggle("is-completed");
    console.log(`Toggled todo ID: ${li.dataset.id}`);
  }
});
Why This Wins:
• Zero Memory Overhead: 1 event listener instead of 5,000.
• Future-Proof: If you append 100 new items to the list later via JavaScript, they will work instantly without needing new event listeners!

⚠ Common Beginner Mistakes
  • Invoking the handler function when adding: btn.addEventListener("click", doThing()) runs immediately on load. Write doThing without parentheses!
  • Using event.target without .closest(): If a button contains an <svg> or <span>, event.target will be the svg! Using e.target.closest("button") safely finds the button regardless of which inner icon was clicked.
  • Overusing stopPropagation(): Halting event bubbling blindly breaks analytics tracking, global dropdown dismissals, and document-level shortcut listeners. Use with care.
💡 Pro Tips from Senior Engineers
  • Self-cleaning listeners with { once: true }: If an action should only happen once, pass the option: btn.addEventListener("click", runInit, { once: true }); — it unbinds itself automatically!
  • Passive listeners for scrolling: When listening to touch or wheel events, pass { passive: true } to tell the browser you won't call preventDefault(), boosting scroll frame rates to 120fps.
  • AbortController for bulk removal: Modern JS allows removing dozens of event listeners at once using an AbortController signal!
⚡ Quick Recap
  • Attach events with addEventListener(type, handler).
  • Events propagate in 3 phases: Capturing → Target → Bubbling (bubbles up).
  • event.target is the element clicked; event.currentTarget is the element with the listener.
  • event.preventDefault() stops default browser action (links, forms).
  • event.stopPropagation() stops the event from bubbling higher.
  • Event Delegation attaches one listener to a parent and uses e.target.closest().

Exercise 1 (Easy): One-Time Click Listener Easy

Write an addEventListener call on claimBtn for the "click" event that automatically removes itself after firing once, using options.

Hint: Pass { once: true } as the third argument.
Solution:
claimBtn.addEventListener("click", handleClaim, { once: true });
Exercise 2 (Medium): Prevent Form Submission Reload Medium

Write an event listener on contactForm for the "submit" event that cancels the browser's default page reload and logs "Form submitted via AJAX".

Hint: e.preventDefault().
Solution:
contactForm.addEventListener("submit", (e) => {
  e.preventDefault();
  console.log("Form submitted via AJAX");
});
Exercise 3 (Hard): Delegated Accordion Handler Hard

Given <div class="accordion-container"> containing many <button class="accordion-trigger"> elements, write a single delegated listener on the container that toggles class "is-open" on the clicked trigger.

Hint: const trigger = e.target.closest(".accordion-trigger"); if (trigger) ...
Solution:
const container = document.querySelector(".accordion-container");
container.addEventListener("click", (e) => {
  const trigger = e.target.closest(".accordion-trigger");
  if (trigger) {
    trigger.classList.toggle("is-open");
  }
});
