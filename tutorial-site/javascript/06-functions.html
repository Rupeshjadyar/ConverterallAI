1. Function Declarations vs Function Expressions

There are two primary traditional ways to define a function in JavaScript:

Code Example 1: Declarations vs Expressions

javascript
// 1. FUNCTION DECLARATION: Hoisted to the top of its scope!
// You can call this function BEFORE its line of definition!
console.log(calculateTax(100)); // Works! Returns 10

function calculateTax(subtotal) {
  return subtotal * 0.10;
}

// 2. FUNCTION EXPRESSION: Stored inside a variable (Not hoisted!)
// Must be defined BEFORE calling it!
const formatCurrency = function(amount) {
  return "$" + amount.toFixed(2);
};

console.log(formatCurrency(10.5)); // "$10.50"

2. Parameters vs Arguments

These two words are frequently confused by beginners:
• Parameters: The named placeholder variables listed in the function definition.
• Arguments: The concrete, actual values passed into the function when you invoke it.

Code Example 2: Parameters, Arguments & Defaults

javascript
// 'firstName' and 'role' are PARAMETERS (placeholders)
// 'role = "Viewer"' sets a default value if no argument is passed!
function registerUser(firstName, role = "Viewer") {
  return {
    name: firstName,
    role: role,
    createdAt: new Date().toLocaleDateString()
  };
}

// "Sarah" and "Admin" are the concrete ARGUMENTS passed:
const userA = registerUser("Sarah", "Admin");

// If second argument is omitted, default "Viewer" is applied:
const userB = registerUser("David");
console.log(userB.role); // "Viewer"

3. Rest Parameters: Handling Arbitrary Arguments

When you don't know how many items a user will pass into a function (like summing numbers), use the modern Rest Parameter (...args):

Code Example 3: The Rest Parameter

javascript
// '...numbers' packs all passed arguments into a standard array
function sumAll(...numbers) {
  let total = 0;
  for (const n of numbers) {
    total += n;
  }
  return total;
}

console.log(sumAll(5, 10));             // 15
console.log(sumAll(1, 2, 3, 4, 5, 10)); // 25

4. Modern Arrow Functions (=>)

Introduced in ES6, arrow functions provide a compact, expressive syntax for writing functions. They are the standard syntax for callbacks and utility methods:

Code Example 4: Arrow Function Syntax Evolution

javascript
// 1. Standard Multi-line Arrow Function:
const multiply = (a, b) => {
  const result = a * b;
  return result;
};

// 2. Concise Single-Line IMPLICIT RETURN:
// No curly braces, no 'return' keyword needed!
const square = (n) => n * n;
console.log(square(5)); // 25

// 3. Single parameter can omit parentheses:
const double = x => x * 2;

// 4. Returning an object literal implicitly (wrap in parentheses!):
const makePoint = (x, y) => ({ x: x, y: y });
console.log(makePoint(10, 20)); // { x: 10, y: 20 }

5. First-Class Functions: Callbacks in Action

In JavaScript, functions are First-Class Citizens. This means functions are treated just like any other value: You can assign them to variables, pass them as arguments to other functions (callbacks), and return them from functions:

Code Example 5: Functions as Arguments (Callbacks)

javascript
function executeCalculation(num1, num2, operationCallback) {
  console.log("Preparing operation...");
  return operationCallback(num1, num2);
}

const add = (a, b) => a + b;
const subtract = (a, b) => a - b;

// Passing the function definitions into executeCalculation:
console.log(executeCalculation(20, 5, add));      // 25
console.log(executeCalculation(20, 5, subtract)); // 15

6. Pure Functions vs Side Effects

A Pure Function is a function where:
• Given the same inputs, it ALWAYS returns the exact same output.
• It causes ZERO side effects (does not alter external global variables, DOM, or files).

Code Example 6: Pure vs Impure Functions

javascript
// IMPURE FUNCTION (Relies on external state; causes side effects):
let globalCartTotal = 0;
function addToCartImpure(price) {
  globalCartTotal += price; // Mutating external variable! Unpredictable!
}

// PURE FUNCTION (Self-contained, predictable, easy to test):
function calculateTotalPure(currentTotal, newPrice) {
  return currentTotal + newPrice; // Returns new value without touching outside world!
}

⚠ Common Beginner Mistakes
  • Forgetting the return keyword in multi-line functions: If a function opens curly braces { }, it MUST explicitly use return myVal;. Omitting it results in undefined!
  • Returning object literals implicitly without parentheses: Writing () => { a: 1 } fails because JS treats { } as function body block braces. Wrap in parentheses: () => ({ a: 1 }).
  • Calling a function when passing it as a callback: Writing btn.addEventListener("click", handleClick()) calls the function immediately on page load instead of waiting for the click! Write handleClick (without parentheses).
  • Assuming Arrow Functions have their own this: Arrow functions do not bind their own this context; they inherit it from the outer parent scope.
💡 Pro Tips from Senior Engineers
  • One job per function (Single Responsibility): A function should do one thing and do it well. If your function is calculating a price AND updating the DOM AND saving to localStorage, split it into 3 clean functions!
  • Name functions as verbs: Functions execute actions. Name them accordingly: fetchUserData(), validateEmail(), calculateInvoice().
  • Use default parameters over manual checks: Replace if (!tax) tax = 0.05; with function calc(price, tax = 0.05).
⚡ Quick Recap
  • Function declarations are hoisted; function expressions are not.
  • Parameters are placeholders in definition; arguments are actual values passed.
  • Functions return undefined if no return statement is executed.
  • Arrow functions provide concise syntax: (a, b) => a + b.
  • Wrap implicitly returned objects in parentheses: () => ({ id: 1 }).
  • Pure functions avoid external mutations, making applications stable and testable.

8. Practice Coding Exercises

Exercise 1 (Easy): Convert to Arrow Function Easy

Convert this standard function declaration into a single-line arrow function with implicit return:
function isAdult(age) { return age >= 18; }

Hint: const isAdult = age => age >= 18;
Solution:
const isAdult = age => age >= 18;
Exercise 2 (Medium): Default Greeting Function Medium

Write an arrow function greetUser that takes a name parameter defaulting to "Friend" and returns "Welcome, [name]!".

Hint: const greetUser = (name = "Friend") => `Welcome, ${name}!`;
Solution:
const greetUser = (name = "Friend") => `Welcome, ${name}!`;
Exercise 3 (Hard): Find Maximum with Rest Parameter Hard

Write a function findMax(...nums) that accepts any number of numerical arguments and returns the highest number without using Math.max().

Hint: let max = nums[0]; for (const n of nums) ...
Solution:
function findMax(...nums) {
  if (nums.length === 0) return null;
  let max = nums[0];
  for (const n of nums) {
    if (n > max) max = n;
  }
  return max;
}
